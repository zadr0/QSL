可选字段

写成 T? 的字段是可选字段。帧必须说明哪些可选字段存在。QSL 有三种表示方式，另外还有 opt_table，它只改变生成的读取代码如何分派。

模式 属性 存在信息的存储方式 字节与默认模式相同
默认 无 存在字段的个数及其标签 是
位图 optionals=bitmap 每个可选字段占一位的掩码 否
长度索引 predict_seq 由载荷长度推导 否
读取表 opt_table 与所组合的模式相同 是

默认：个数和标签

Section titled “默认：个数和标签”

不加属性时，帧以头部开始：先是存在的可选字段个数，然后是每个存在字段的标签码。接着是必填字段的值，最后按声明顺序写入存在的可选字段的值。只有一个可选字段的类型只用一个存在位。生成的读取代码对标签做 match 来分派。

头部从最低有效位开始打包。个数占 bit_length(optional_count) 位。每个标签码等于字段标签减 1，占 bit_length(max_tag - 1) 位。不使用 compact 时，头部会填充到整字节。

仓库中的 optionals 示例编码 id = 42，以及 f0 = 11、f1 = 22、f2 = 33 中的部分字段：

存在的字段 帧
无 00 2a 00 00 00
f0、f2 36 2a 00 00 00 0b 21
f0、f1、f2 e7 2a 00 00 00 0b 16 21
id 的标签是 1，f0 到 f2 的标签是 2 到 4，因此每个标签码占 2 位，个数也占 2 位。对于 f0 和 f2，头部依次是个数 2（10）、标签码 1（01）和 3（11）：0b110110 = 36。去掉 opt_table 后帧完全相同。

位图

Section titled “位图”

optionals=bitmap 写入一个只覆盖可选字段的小端序掩码。掩码宽度取决于类型中可选字段的个数：

可选字段数 0 1–8 9–16 17–32 33–64 65–128
掩码字节数 0 1 2 4 8 16
第一个可选字段的标记为 1，存放在最高有效位。读取代码用 trailing_zeros 查找置位的位，因此存在的值按标记从大到小的顺序写入和读取。必填字段的值保持声明顺序。

切换字段即可看到帧的变化。对于 &P[safety,optionals=bitmap,opt_table]{u8 id;u16? a;u8? b;}，当 id = 9、a = 0x1234、b = 7 时，帧为 c0 09 07 34 12：依次是掩码、id、b，最后是小端序的 a。

使用 [safety] 时，解码器在遍历掩码之前会做一次检查，确认类型中不存在的标记都没有被置位。

格式变更

位图 v2（0.2.0 及以后）与早期覆盖所有字段的掩码不兼容。两端需要一起升级。

长度索引：predict_seq

Section titled “长度索引：predict_seq”

使用 predict_seq 时，解码器根据载荷长度推断哪些可选字段存在。这要求每种存在字段的组合都对应不同的长度：

  • 只有一个可选字段时，可以通过输入是否结束来判断；
  • 有多个可选字段时，它们必须是固定大小，且任意子集的大小之和互不相同。

有歧义的组合以及编码后为零字节的可选字段会在构建时被拒绝。由于存在信息来自长度，可信解码器除了指针还需要输入长度。

设置了 optionals=bitmap 时，predict_seq 会被忽略。与 compact 同时使用是构建错误。

predict_seq 与 opt_table 组合

Section titled “predict_seq 与 opt_table 组合”

[predict_seq,opt_table] 保持 0.2.0 之前单独使用 [opt_table] 时生成的格式。长度图最多支持 12 个字段和 65535 字节的载荷。超过 12 个字段时，所有字段都必须具有相同的固定宽度，上限为 64 个字段。如果你有 0.2.0 之前用 [opt_table] 写入的帧，请把两端都改成 [predict_seq,opt_table]。

读取表：opt_table

Section titled “读取表：opt_table”

opt_table 用一张静态的读取函数表代替 match，每个可选字段一个函数，按标记索引。它不改变字节，也不改变 schema 哈希，可以与默认格式、compact 和位图一起使用。

通过表做间接调用不一定比 match 快。保留它之前，先用你的数据测一测。

初始值

Section titled “初始值”

在数值字段上使用 |default=N| 会为类型生成 impl Default，该字段的初始值为 N。可选字段的默认值为 Some(N)。它不改变编码格式，也不改变 schema 哈希。见 default=N。
