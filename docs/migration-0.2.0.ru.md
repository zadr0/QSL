# Диспетчеризация optional v2 и нативные регионы

Контракт QSL 0.2.0: анализатор qsl-lexer, Rust-генератор qsl-interpreter и переносимый runtime. BM несовместим со старым BM-форматом; остальные описанные режимы сохраняют собственные контракты. Платформенные Windows-модули и Cargo-feature native удалены. Обе стороны обмена обновляются согласованно.

## Разделение механизмов

| Механизм | Что использует | Что делает |
|---|---|---|
| Обычный режим | Счётчик и теги optional-полей | Вызывает обработчик через `match` |
| BM: `optionals=bitmap` | Маску присутствия | Обходит только установленные биты |
| OT: `opt_table` | Проверенный маркер | Выбирает функцию чтения из таблицы |
| PS: `predict_seq` | Длину payload | Определяет возможную последовательность optional-полей |

QPS остаётся обратимым сжатием на основе операнда. Предсказание к нему не относится. Атрибуты опциональны; обязательные поля должны располагаться перед опциональными. В BM порядок задаёт маска, поэтому PS для него не применяется. OT совместим и с BM, и с PS.

## Новый формат BM

Количество optional-полей определяет ширину: 0 / 1–8 / 9–16 / 17–32 / 33–64 / 65–128 полей занимают 0 / 1 / 2 / 4 / 8 / 16 байт маски. Обязательные поля в маску не входят. Порядок байтов — little endian. Маркер первого optional-поля равен 1 и расположен в старшем бите.

Чтение выполняет `marker = WIDTH - mask.trailing_zeros()` и `mask &= mask - 1`. Поэтому присутствующие optional-поля читаются в обратном порядке объявления. Запись использует тот же порядок. Обязательные поля сохраняют исходный порядок.

```qsl
&P[safety,optionals=bitmap,opt_table,predict_seq] {
    u8 id;
    u16? a;
    u8? b;
}
```

Для `id=9, a=Some(0x1234), b=Some(7)` кадр равен `C0 09 07 34 12`: маска, id, b, a. Здесь OT включён, а PS не применяется. Без OT байты те же, но обработчик выбирается через `match`.

Это согласованная замена старого BM: обе стороны обмена должны обновиться вместе либо договориться о версии вне кадра. Канонический хэш BM включает ревизию 2 и ширину маски. Хэш не заменяет рукопожатие или аутентификацию. Обычный формат без BM сохраняется: теги находятся в прежнем заголовке, после которого цикл читает соответствующие значения. Теги не переносятся между значениями payload.

## Safety и unchecked

Для непустой маски до цикла проверяется `WIDTH - trailing_zeros(mask) <= optional_count`. Это её наибольший маркер: оставшиеся будут меньше. Так отсекаются лишние биты и обосновывается индекс OT. Для пустой маски проверка не нужна. Теговый режим проверяет счётчик, порядок и допустимость тегов.

Курсор проверяет границы кадра, диапазоны, UTF-8, размер распакованной строки, бюджет восстановленных данных и отсутствие лишнего хвоста. При ошибке `deserialize_checked_into` не публикует частично заполненный объект. Временные значения уничтожаются обычным образом.

Unchecked-методы сохранены. Вызывающая сторона обеспечивает корректность кадра, достаточную инициализированную память для регистрового чтения, время жизни и отсутствие недопустимых пересечений. Предварительная проверка другого кадра этих гарантий не даёт.

Для пользовательского компактного значения читается `COMP_SIZE`, но бюджет восстановленных данных учитывает `SIZE`. Массив проверяется по фактической компактной ширине элемента; перед безопасной записью валидируется каждый элемент. Скрытые выделения памяти внутри пользовательского кодека остаются его ответственностью.

## Пользовательские примитивы

Макрос внедрения полей и полиморфный кодек — разные механизмы. Существующие реализации `QslCustom` сохраняются. Автоматической замены их формата на встроенный числовой тип нет.

В общем Rust-модуле приложения и build-скрипта:

```rust
qsl_lexer::qsl_primitive!(pub struct DeviceId(u32);range=(1,100););
```

Поддерживаются u8/i8, u16/i16, u32/i32, u64/i64. Макрос проверяет вид числа, размер, выравнивание, смещение поля, отсутствие Drop и допустимость диапазона. Обычный кодек записывает little endian. Компактный кодек хранит ранг `value-min` минимальным целым количеством байт. Соседние встроенные поля с ним автоматически не объединяются в один регистр. Постоянный диапазон занимает 0 компактных байт; ограничения PS на нулевую ширину optional-кодека сохраняются.

```rust,ignore
use qsl_interpreter::prelude::*;
let builder = QslSchemaBuilder::new()
    .with_primitive::<DeviceId>("DeviceId")?
    .with_source("&Packet[safety,compact,optionals=bitmap,opt_table]{DeviceId id;DeviceId? extra;}")?;
let rust = builder.use_interpreter()?;
```

Регистрация предшествует разбору. Rust проверяет ABI также в приложении через сгенерированные константные утверждения, включая элементы массивов. Зарегистрированный примитив допускается внутри QSL-массива. После импорта Rust-шаблонов метаданные применяются повторно.

Для использования в нативном регионе приложение отдельно вызывает `qsl_lexer::qsl_native_primitive!(DeviceId,u32);`. Макрос использует существующий `NativeField` и проверяет значение до создания безопасного представления. Произвольные ручные `unsafe impl` остаются обязанностью разработчика: сравнение размеров не доказывает семантику его методов. Широкая автоматическая трансмутация пользовательских типов не добавляется. Вложенная схема внутри кодека имеет собственную область optional-маркеров.

## Вложенные структуры регионов

```qsl
&Parent[safety] {
    #region(aggressive_transmutate="Meta");
    u64 id;
    u32 value;
    str(4) tag;
    #end_region;
    str(3..10) name;
}
```

Генерируются самостоятельная `#[repr(C)] Meta { id:u64, value:u32, tag:[u8;4] }` и `Parent { Meta:Meta, name:String }`. Поля региона не раскрываются обратно в Parent. Старое написание `aggresive_transmutate` принимается как синоним.

COPY создаёт собственный объект; при несовпадении native- и wire-layout использует сборку по полям. LIFETIME создаёт ссылку только после проверки размера, смещений, little endian, выравнивания входа и всех значений. Обычный Vec не гарантирует выравнивание произвольной структуры: при нарушении checked-чтение возвращает ошибку. COPY такого выравнивания входного адреса не требует.

Вложенные регионы создают иерархию типов. Повторные идентичные определения переиспользуются. Конфликты имён, рекурсия, пересекающиеся или пустые регионы, неизвестные native-типы, динамические и optional-поля внутри региона отклоняются. Фиксированные строки представлены `[u8;N]`; лимит стека действует и для native-строк/массивов. Native-дескриптор допускает до 64 инициализированных листьев, вложенность регионов ограничена 64.

Rust-шаблон `#[qsl::schem_macro(aggressive_transmutate)]` сохраняет исходный Rust-тип как вложенное поле без дублирующего определения. Обычные макросы внедрения полей продолжают раскрываться. Явный `repr(align(...))` учитывается; дополнительный padding может исключить LIFETIME при доступном COPY.

## Проверки

[Проверочный проект](../qsl-interpreter/tests/optional-v2/README.md) содержит граничные ширины BM, сравнение match/OT, вложенные индексы, регионы, пользовательские примитивы, массивы, сжатые строки и повреждённые кадры. Узкий Criterion сравнивает только текущую диспетчеризацию; результаты не являются сетевой пропускной способностью или общей оценкой всех схем QSL.

[Lean4](../qsl-lexer/proofs/README.md) проверяет арифметическую границу индекса таблицы при явно указанных предпосылках. Доказательства не покрывают указатели Rust, произвольные реализации трейтов и машинный код. Тесты повреждённых кадров также не заменяют полного доказательства безопасности памяти.
