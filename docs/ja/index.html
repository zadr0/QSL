スキーマを書けば、コードは QSL が書く

Quick Schema Language (QSL) は Rust 向けのスキーマ言語です。メッセージのフィールド、各数値の範囲、文字列の長さの上限を一度書いておくと、cargo build の間に QSL がそれを構造体に変え、バイト列への書き出しと読み戻しを行うコードも生成します。

コーデックを手書きする必要はなく、実行時にスキーマを解析することもありません。この例のように [safety] を付けると、スキーマに合わないバイト列は User ではなくエラーとして返ってきます。プログラムの残りの 2 つのファイルはクイックスタートにあります。
