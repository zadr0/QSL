QSL

Архитектура QSL

Полное руководство · Математика · Замеры

QSL делит работу на анализ при сборке и специализированное исполнение. DEQ → парсер → раскрытие Rust-полей → проверка инвариантов → план регистров/смещений → генерация → rustc/LLVM.

В runtime приложение выбирает владение и регион, записывает один согласованный wire-формат и читает его проверяемым либо доверенным API. Порядок [required][optional] обязателен; остальные режимы включаются явно.

QPS преобразует числовые операнды и точно восстанавливает данные. predict_seq определяет состояние по длине; opt_table выбирает функцию чтения по тегу. Общий byte-envelope сначала восстанавливает внутренний кадр; обычные полевые смещения применяются после этого.

Полное руководство содержит контракты методов, схему всех модулей, отображения типов, ограничения опций, стоимость памяти и ошибки. API-index содержит 625 публичных объявлений текущего снимка; действуют feature-gates.

Безопасные методы генерируются каждой схеме. Нативный курсор проверяет весь кадр и общий бюджет до указательного декодера; QPS проверяет исходную длину до восстановления. Контракт · Хэши схем.
