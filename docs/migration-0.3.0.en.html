QSL 0.3.0: qsl-core and string representations

QSL 0.3.0 moves shared contracts into qsl-core 0.1.0 and removes retired string APIs. Update qsl, qsl-lexer and qsl-interpreter together to 0.3.0. The procedural implementation remains qsl-macros-impl 0.1.0. Moving modules does not itself change BM v2 or ordinary string wire formats.

Crate boundaries

CrateResponsibilityDependencies
qsl-coreErrors, schema contracts, shared analyses, I/O, UTF-8 storage, validation, buffers and low-level codecsno lexer/interpreter dependency
qsl-lexerTokens, QSL/DEQ parsing, loading, template expansion and schema builderqsl-core
qsl-interpreterRust-specific preparation and Rust source generationqsl-lexer
qslApplication facade, macros and compatible entry pointscore, lexer, interpreter, macro implementation

Old module paths contain re-exports and associated tests. Core owns each implementation once, including one QslError identity and I/O contracts. Core contains neither a source parser nor a Rust generator. A future LLVM backend can consume shared contracts without executing the interpreter.

Strings

ChoiceRust representationOwnership
ordinary stringStringowned heap storage
aggressive, finite range within STACK_LIMITStackString<N>inline capacity
binary_opt=inline within STACK_LIMITInlineString<N>inline capacity and independent length header
binary_opt=view&strborrowed UTF-8 from the input

New initializes a fresh destination. Reuse updates an initialized destination; prepare sufficient String capacity first. These are method modes, not additional string types. binary_opt=guard and binary_opt=true are rejected. Utf8Guard, Utf8CopyGuard and byte-string representations are removed. Explicit Rust &str fields preserve owned String siblings. Fixed native byte fields retain [u8; N].

STACK_LIMIT defaults to 256 B. Ordinary oversized inline strings fall back to String. Raising the budget is explicit. An &str result requires its source frame to remain alive and immutable.

Safety

Checked methods still enforce bounds, UTF-8, domains, actual decompressed lengths and aggregate budgets. Unchecked methods remain available with caller obligations for valid frames, lifetimes, disjoint storage and capacity. Tests cover forged lengths, invalid UTF-8, every truncation and mixed ownership.

Current measurements

Nine Criterion cases separate String new/reuse, StackString new/reuse, InlineString new/reuse and &str. The main set has 1024 Cyrillic scalars / 2048 useful bytes; the control has 255 ASCII scalars. This benchmark explicitly sets STACK_LIMIT=2048 for inline containers; it is not the default budget. Validation and buffer preparation precede timing; new String includes allocation and Drop. Warm-up 15 s, measurement 10 s, 200 samples, 99% CI, process memory limit 8 GiB. See the interactive report.
