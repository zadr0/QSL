QSL 0.2.0 — явная диспетчеризация optional и переносимый runtime

QSL генерирует Rust-кодеки при сборке для заранее согласованных схем. Выпуск меняет часть pre-1.0 API и BM-формат, разделяя обход маски, предсказание длины и выбор читателя. Универсальный сетевой протокол и LLVM-backend не добавляются.

Пакеты

  • qsl 0.2.0: переносимый runtime и совместимый фасад компилятора.
  • qsl-lexer 0.2.0: сбор схем и анализ при сборке.
  • qsl-interpreter 0.2.0: понижение и генерация Rust.
  • qsl-macros-impl остаётся 0.1.0: его реализация не менялась.

Изменения

  • BM использует только optional-поля, little-endian маску u8/u16/u32/u64/u128 и цикл установленных битов по убыванию маркера. Safety до обхода отклоняет лишние биты.
  • Default выбирает читателя через match, OT переиспользует обработчики. PS определяет присутствие по длине и использует OT; порядок BM он не меняет. QPS остаётся обратимой упаковкой по операнду, а не предсказанием.
  • Именованные native-регионы создают настоящие вложенные типы. Вложенные и повторные определения поддерживают COPY и проверяемый выровненный LIFETIME.
  • Проверяемые макросы примитивов задают явный числовой/layout-контракт, сохраняя QslCustom. Бюджет восстановления учитывает SIZE; compact-массив использует COMP_SIZE и проверяет значения элементов.
  • Удалены feature native, windows-sys и Windows-сокеты/IPC-регионы. SerOut, std TCP, native-layout и unchecked-методы сохраняются. Обычная сериализация использует Vec/срезы.
  • Обновлены полное руководство RU/EN, справочник атрибутов, индекс исходного API, примеры и переход. Документация пакетов — на английском.

Переход

BM v2 несовместим со старым BM-кадром. Обновляйте обе стороны вместе либо согласуйте версию вне кадра. Обычный счётчик/теги без BM сохраняются. Удалите features=["native"] из зависимостей. Прежний стандартный Vec/срез API работает; клиенты бывшего SerOut-returning режима адаптируются явно. Внешнюю IPC-память и транспорт обеспечивает приложение.

Проверки

С выпуском сохраняются тесты, строгий Clippy, сборка документации, проверки упакованных крейтов и отдельный клиент из registry. Lean4 проверяет явно описанную арифметику индексов, а не всю модель памяти Rust. Исторические замеры сохраняют исходные версии. Четыре случая Criterion от 7 ноября не приняты как строгий результат из-за фоновой загрузки CPU 27–64%; ускорение не заявляется.
