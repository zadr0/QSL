# QSL 0.3.0

## Общее ядро и строки

qsl, qsl-lexer и qsl-interpreter имеют версию 0.3.0; новый qsl-core — 0.1.0. Реализация атрибутных макросов остаётся 0.1.0. Требуется Rust 1.98+. Лицензия MIT.

Общие типы схем, ошибки, конфигурация, wire-анализ, I/O, валидация, строки и буферы принадлежат qsl-core. Он не зависит от парсера или генератора. Прежние пути импорта сохраняются через re-export.

Переменные UTF-8 строки: String, &str, StackString и InlineString. Guard и байтовые строковые режимы удалены. binary_opt=view возвращает &str; соседние String сохраняют владение. New/reuse — режимы назначения. STACK_LIMIT по умолчанию 256 B; превышение переводит обычное встроенное хранение в String. Checked- и unsafe-методы сохранены.

## Совместимость и установка

Это несовместимое изменение API до 1.0. Для обычных строк и BM v2 перенос модулей не меняет байты кадра. Схема и влияющие на формат опции должны совпадать у сторон.

```toml
[dependencies]
qsl = "=0.3.0"

[build-dependencies]
qsl = "=0.3.0"
```

## Проверки и измерения

Проверяются четыре пакета, сгенерированные структуры, владение строками, повреждённые длины/UTF-8 и независимый потребитель реестра. Результаты публикации и логи находятся в reference/crates-release-0.3.0. Девять сохранённых замеров Criterion относятся к явно указанным входам и снимку исходников до изменения метаданных версии. Фон 8,2% не позволяет считать прогон строгим доказательством скорости. Новое ускорение публикацией не заявляется.
