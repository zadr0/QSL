# QSL 0.2.0 — explicit optional dispatch and portable runtime

QSL is a build-time Rust binary-codec generator for agreed schemas. This breaking pre-1.0 release separates mask traversal, length prediction and reader dispatch; it does not add a universal network protocol or LLVM backend.

## Packages

- qsl 0.2.0: portable runtime and compiler facade.
- qsl-lexer 0.2.0: schema collection and build-time analysis.
- qsl-interpreter 0.2.0: Rust lowering and generation.
- qsl-macros-impl remains 0.1.0; its implementation is unchanged.

## Changes

- BM has optional-only little-endian masks selected from u8/u16/u32/u64/u128. A set-bit loop reads descending optional markers; Safety rejects spare bits before dispatch.
- Default uses match; OT shares optional readers. PS derives presence from length and reuses OT handlers. PS cannot reorder BM. QPS remains reversible operand packing, not prediction.
- Named native regions create real nested Rust types. Nested/reused definitions support COPY and checked aligned LIFETIME.
- Explicit scalar-wrapper macros validate integer/layout/domain contracts while retaining QslCustom codecs. Restored budgets charge original SIZE; custom arrays respect COMP_SIZE and validate element values.
- Remove the native feature, windows-sys and Windows-only socket/IPC modules. Keep SerOut, std TCP, native-layout helpers and unchecked APIs. Ordinary serialization consistently uses Vec/slices.
- Update the complete RU/EN guide, attribute reference, source API index, examples and migration instructions. Package documentation is English.

## Migration

BM v2 is incompatible with old BM frames. Upgrade peers together or negotiate outside the frame. Ordinary non-BM count/tag bytes are preserved. Remove features=["native"] from dependencies. Existing default Vec/slice calls continue to work; former SerOut-returning feature clients must adapt explicitly. Applications own external shared-memory and transport facilities.

## Evidence

Tests, strict Clippy, documentation builds, packaged-crate checks and a registry-only consumer are recorded with this release. Lean4 checks documented arithmetic index bounds, not the whole Rust memory model. Historical timing profiles retain their versions. Four November 7 Criterion cases are **not accepted as strict performance results** because of 27–64% observed background CPU activity; no speedup is claimed.

Release assets contain the three .crate packages, an offline documentation archive and SHA-256 checksums. GitHub also supplies the tagged source archive. Rust 1.98+; MIT.
