Início rápido

Você precisa do Rust 1.98 ou mais recente. O resultado é um programa que codifica um valor User em bytes e o decodifica de volta.

  • Directoryqsl-demo/
    • Cargo.toml
    • build.rs
    • user.qsl
    • Directorysrc/
      • main.rs

  1. Crie o projeto:

  2. Adicione o qsl ao Cargo.toml duas vezes: em [dependencies] para o programa e em [build-dependencies] para o build.rs. Mantenha a seção [package] que o Cargo criou. Use a mesma versão nos dois lugares.

  3. Descreva a mensagem em user.qsl, ao lado do Cargo.toml:

    &User declara um tipo. u64 id é um campo do tipo u64 chamado id. str(1..100) é uma string de 1 a 100 bytes de UTF-8. [safety] adiciona os métodos de decodificação verificada usados mais abaixo.

  4. Gere o código Rust em tempo de build. Crie o build.rs na raiz do projeto:

    build_qsl_files grava qsl_gen.rs em OUT_DIR e avisa o Cargo para rodar o build.rs de novo quando user.qsl mudar. O segundo argumento lista arquivos de configuração .deq. Por enquanto não há nenhum.

O que aconteceu

Seção intitulada “O que aconteceu”

O frame tem 15 bytes: 8 para id, um prefixo de comprimento de 4 bytes para name e 3 bytes de UTF-8. O esquema permite de 1 a 100 bytes para name, então deserialize_checked rejeita um frame cujo prefixo de comprimento esteja fora desse intervalo antes de alocar a string.

serialize_checked verifica o valor contra o esquema antes de escrever. Os dois métodos retornam qsl::QslResult. O tipo de erro é QslError.

Regras para conhecer desde o início

Seção intitulada “Regras para conhecer desde o início”
  • Os campos obrigatórios vêm primeiro. Um campo obrigatório depois de um opcional é erro de build.
  • Os limites de strings e arrays são inclusivos. Strings são medidas em bytes de UTF-8; arrays, em elementos.
  • deserialize_checked e deserialize_checked_into só existem em tipos com [safety]. Os decodificadores sem verificação são sempre gerados e exigem um frame válido.
  • MAX_DATA_SIZE limita o frame e os dados decodificados. O padrão é 65535 bytes. Para mudar, use um arquivo DEQ.
