Builder and DEQ

The Builder describes schemas in Rust. DEQ stores constants and shared settings. Both use the same analysis and format rules; matching inputs must produce the same result.

How a schema is built

Section titled “How a schema is built”

QslBuilder holds settings and schemas. A schem callback calls name, field and type methods; build validates the declarations. use_interpreter selects Rust generation. Complete build.rs.

Methods and arguments

Section titled “Methods and arguments”

name(name: &str)

Starts a schema. Its name becomes the Rust type name; following field declarations belong to it.

name: &str
A nonempty valid Rust identifier.

field(name: &str)

Names the next field. The following type method, such as u32 or str, commits the field.

name: &str
Field name; duplicates are rejected.

u32(min: u32, max: u32, default: u32, optional: bool)

Declares an integer. Other integer methods use the same arguments with their corresponding Rust type.

min, max
Inclusive value bounds. In compact mode they determine the encoded bit width.
default
Initial value for a new object; must belong to the domain. Never replaces an absent optional on the wire.
optional: bool
true allows absence. All optional fields must follow required fields.

str(min: u32, max: u32, decompress: bool, optional: bool)

Declares a UTF-8 string. Length is bytes: “Яa” occupies 3 B.

min, max
Inclusive UTF-8 byte bounds. max affects the header and storage capacity.
decompress: bool
true selects QSL-LZ. The codec retains raw data when compression is not worthwhile.
optional: bool
Allows the entire string to be absent. Empty and absent are distinct states.

array::<T>(min: u32, max: u32, optional: bool)

Declares a variable-length array. T supplies QslFieldType element metadata.

T
Element type. Memory budgets use its native size; wire uses its codec.
min, max
Element count, not bytes. Affects lengths, capacity and Vec/InlineArray storage.
optional: bool
Allows absence; an empty array remains a distinct value.

fstr(size: u32, optional: bool) / farray::<T>(size: u32, optional: bool)

Fixes the length. A variable-length header is unnecessary; storage still obeys STACK_LIMIT.

size: u32
Bytes for fstr; elements for farray.

padding(bits: u32)

Adds zero wire bits. Byte multiples retain legacy Padding behavior; non-byte widths require compact.

bits: u32
Bit count. Checked decoding requires zero padding.

domain(domain, default_bits: Option<u128>, optional: bool)

Declares an exact interval, progression or value set. Ranks map reversibly to values.

domain
NumericDomain: native width, signedness and valid values.
default_bits
None omits an explicit initializer; Some supplies the initial native bit pattern.

compact() / auto() / inline() / ot() / ps() / bm() / q16()

These methods take no arguments and enable individual mechanisms. build validates compatibility.

compact / q16
Change wire encoding; peers need matching schemas.
auto / inline
auto changes physical layout; inline sets Rust method policy.
ps / ot / bm
Length index / reader by tag / presence mask, respectively.

group(enabled: bool) / pointing(enabled: bool) / aggresive(shift: bool, bitmap: bool)

Permits proven optimizations. A flag alone does not make arbitrary objects safe for memcpy or SIMD.

enabled: bool
true permits candidate analysis; safety and profile requirements still apply.
shift / bitmap
Physical len+1 lengths / private optional slots and mask. This is not wire BM.

dyn_line(width: u32, revision: u32) / dyn_index(width: u32, strict: bool, revision: u32)

Selects the separate dyn v1 format. tag(u64) assigns field metadata tags.

width: u32
line: 16/32/64; index: 32/64. index16 is unsupported.
strict: bool
Selects the strict indexed-schema variant.
revision: u32
Schema revision in the agreed dyn contract.

DEQ settings

Section titled “DEQ settings”

MAX_DATA_SIZE

Section titled “MAX_DATA_SIZE”

Default: 65535 B. max_data_size(bytes: u32).

Bounds input frames, restoration and aggregate data before allocation. Not an RSS limit.

STACK_LIMIT

Section titled “STACK_LIMIT”

Default: 256 B. stack_limit(bytes: u32).

Separate strict limit for inline strings/arrays. A larger max_data_size does not increase it.

QSL_RT

Section titled “QSL_RT”

Default: false. with_rt().

Enables static slots only for eligible bounded schemas.

QSL_RT_DEFAULT

Section titled “QSL_RT_DEFAULT”

Default: 16. default_rt_slots(slots: u32).

Concurrent slots per eligible schema: 1–64. Exhaustion returns an error.

USE_HASH

Section titled “USE_HASH”

Default: xxHash. use_xxhash128().

xxHash selects XXH3-64; xxHash128 selects XXH3-128. Hashes do not provide authentication.

CPU_PROFILE

Section titled “CPU_PROFILE”

Default: portable. cpu_profile(CpuProfile).

portable or kaby_lake. Changes eligible instruction choices, not wire identity.

Constants

Section titled “Constants”

Typed integer constants are evaluated during the build, including exact u128/i128 values. Duplicate names, overflow and invalid values produce diagnostics.
