# cache · QSL 0.2.0

cache=N задаёт явную политику ёмкости CachedFrame; доказанная максимальная длина кадра должна помещаться. Это хранение/выделение памяти, не часть wire-идентичности. См. loyal_cache и полный контракт памяти.
