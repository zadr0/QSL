# lifetime · QSL 0.2.0

Заимствует поддерживаемые сырые строки/байты из неизменяемого входа, который живёт дольше результата. Фиксированный native-регион может использовать проверяемое выровненное представление; whole-record transmutate+lifetime строже ограничивает layout. Сжатым строкам нужно собственное восстановление, напрямую заимствовать сжатые байты нельзя.
