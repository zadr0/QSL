# `lifetime` — спецификация атрибута

**Статус:** реализовано, кроме оговорки для `safety`: только флаг в этой версии.

## Синтаксис

```qsl
&View[lifetime] { string text; }
```

## Точная механика и wire-эффект

Генерируется View<'a> с &'a str, BorrowSerializable<'a>. Значения заимствуются из wire source, а не создают String. Время жизни и неизменность входа обеспечивает вызывающий код.

## Ограничения и недопустимые сочетания

Custom types и некоторые nested arrays не поддерживают borrowing. Должно существовать реально заимствуемое поле; иначе генерация lifetime-аргумента недопустима.

## Контракт исполнения

При изменении схемы обе стороны должны использовать совместимую ревизию формата. Путь `unsafe` не подтверждает корректность произвольного сетевого ввода; источник, объём данных и диапазоны должны соответствовать схеме.

## Что измерять

Сравнивай полную запись и чтение на одних данных, отдельно метаданные и payload; фиксируй размер сообщения, аллокации, CPU, измерительный профиль и p99. Исходный пример замера:
`utf8_1024/ascii/read_bytes` — [all-estimates.csv](../../data/all-estimates.csv).

## Исходная реализация

`qsl/src/types.rs QslSchema::validate; interpreter.rs generate_lifetime`.
