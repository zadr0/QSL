# binary_opt: владение строкой

[Архитектура](../../architecture.ru.md) · [safety](safety.md)

| Модификатор | Поле Rust | Хранилище |
|---|---|---|
| отсутствует / false | String либо &str при lifetime | Обычное владение схемы |
| true | &'a [u8] | Заимствованные UTF-8-байты; нужен lifetime |
| view | Utf8Guard<'a> | Заимствованное строковое представление; нужен lifetime |
| guard | Utf8CopyGuard | Копирование байтов в собственный/повторно используемый SerOut |
| inline | InlineString<MAX> | Встроенная ограниченная ёмкость и длина |

Фиксированный str(N), включая равные границы, всегда становится `[u8; N]`. Границы задаются в байтах UTF-8, а не в символах Unicode. Модификатор применим только к string/str.

```qsl
&Bytes[lifetime,safety] { str(0..4096) text|binary_opt=true|; }
&View[lifetime,safety] { str(0..4096) text|binary_opt=view|; }
&Copy[safety] { str(0..4096) text|binary_opt=guard|; }
&Inline[safety] { str(0..4096) text|binary_opt=inline|; }
```

CopyGuard не создаёт объект String, но всё равно требует хранилище. Первое создание может выделять память; подготовленное повторное использование исключает повторную подготовку, если ёмкости достаточно. Входной кадр не заимствуется. Заимствованные режимы требуют живого неизменяемого источника. При распаковке нужны байты назначения; неподдерживаемые сочетания с заимствованием/guard отклоняются. Checked-чтение проверяет UTF-8; доверенные методы сохраняют свои предусловия.

Исторические строковые замеры не входят в свежие числовые профили QPS и контроля opt_table. Новая оценка для 1024 символов здесь не заявляется.
