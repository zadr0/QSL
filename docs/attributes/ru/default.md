# default · QSL 0.2.0

Модификатор |default=7| управляет сгенерированной инициализацией в допустимом числовом диапазоне. Он не создаёт присутствие optional, не разрешает недопустимое значение и не меняет явно переданные wire-данные. В хэш формата не входит. Default задаётся явно, а не универсальным unwrap_or_default на горячем пути.
