# inline · QSL 0.2.0

Синтаксис схемы: inline, inline=hint, inline=always, inline=never. Без атрибута решение принимает Rust. Это атрибуты методов, не хранение InlineString и не PS. Wire-хэш не меняется; always может увеличить нагрузку на I-cache и не гарантирует ускорение.
