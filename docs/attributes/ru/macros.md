# macros

[Текущая архитектура и полный контракт](../../architecture.ru.md).

Маркеры #[qsl::qsl_macro] и #[qsl::schem_macro] ставятся на Rust-структуры. Исходные типы сохраняются; вложенные поля раскрываются в содержащей схеме. QSL [macro] не существует.

Оба атрибута доступны через qsl по умолчанию; реализация находится в qsl/macros. Feature rust-macros нужен для импорта Rust-исходников генератором, а не для подключения атрибутов.
