# opt_table

[Текущая архитектура и полный контракт](../../architecture.ru.md).

Статический граф длин и смещений: I(L)=sum((L>boundary) as usize), специализированные функции событий. Теги читаются при неоднозначности; QPS использует известные битовые префиксы. opt_table=legacy сохраняет каталог в кадре.
