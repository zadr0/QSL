# safety · QSL 0.2.0

Генерирует checked-десериализацию и checked-into. Отдельный validate и checked-сериализация остаются явными средствами контроля. До публикации результата проверяются границы, домен, UTF-8, распаковка, optional-метаданные и суммарный полезный бюджет. Unchecked-методы не исчезают; произвольный пользовательский кодек не становится доказанно корректным. MAX_DATA_SIZE по умолчанию 65535.
