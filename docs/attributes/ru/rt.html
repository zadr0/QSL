rt · QSL 0.2.0

DEQ: !config QSL_RT=true; !config QSL_RT_DEFAULT=16;. Статические слоты получают схемы с доказанной конечной верхней границей; общая ёмкость на схему ограничена 64 MiB. serialize() проверяет значения и ждёт lease без выделения выходной памяти. Нельзя удерживать все слоты, ожидая ещё один из той же группы. StaticRegions::try_acquire — неблокирующий API пула с PoolExhausted. Создание исходных String/Vec может выделять память.
