# QPS

[Полные контракты](../../guide.ru.md). QPS — точное сжатие операндами, без предиктования полей. Предиктование выполняет predict_seq; opt_table выбирает читателя по тегу. Числовая специализация упаковывает ограниченные ранги. Общий ByteQps обрабатывает весь сериализованный payload через явные API кодирования/восстановления; QPB3 хранит исходную длину без квантования и имеет заголовок 16 B. По умолчанию Q16; доступны Q2/Q4/Q8/Q16. quant — синоним, state_bits явно выбирает прежнюю D/index-совместимость. При raw-fallback цена заголовка видима; объединение произвольных u8 не гарантирует выигрыша.
