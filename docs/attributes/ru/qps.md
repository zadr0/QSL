# qps · QSL 0.2.0

qps по умолчанию выбирает Q16; qps=Q2/Q4/Q8/Q16 задаёт обратимую числовую упаковку по операнду. Она не предсказывает optional-присутствие и не квантует строки, массивы и их длины. Неподходящая схема сохраняет явно отражаемый raw-путь. Отдельный ByteQps обрабатывает произвольные байты со своим QPB3-заголовком 16 B и буфером восстановления; это не строковая политика атрибута схемы.
