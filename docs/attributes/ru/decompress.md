# `decompress=true` — спецификация атрибута

**Статус:** реализовано, кроме оговорки для `safety`: только флаг в этой версии.

## Синтаксис

```qsl
&PackedView { str(0..4096) text|decompress=true|; }
&FixedUtf8Compressed { str(1024) text|decompress=true|; }
```

## Точная механика и wire-эффект

QSL-LZ v1 для ограниченной динамической строки, fixed framing rev2 для str(N). Сжатие выбирается только при полном выигрыше в размере; иначе raw. Числовые поля рядом не сжимаются автоматически.

## Ограничения и недопустимые сочетания

До 65535 decoded bytes; нельзя комбинировать заимствование true/guard с dynamic decompress. Максимальная производительность зависит от энтропии, буквальной длины и CPU.

## Контракт исполнения

При изменении схемы обе стороны должны использовать совместимую ревизию формата. Путь `unsafe` не подтверждает корректность произвольного сетевого ввода; источник, объём данных и диапазоны должны соответствовать схеме.

## Что измерять

Сравнивай полную запись и чтение на одних данных, отдельно метаданные и payload; фиксируй размер сообщения, аллокации, CPU, измерительный профиль и p99. Исходный пример замера:
`utf8_1024/ascii/read_compressed` — [all-estimates.csv](../../data/all-estimates.csv).

## Исходная реализация

`qsl/src/strings.rs encode_bounded/decode_bounded/fixed v2`.
