# transmutate · QSL 0.2.0

Требует совместимого фиксированного native-хранения. COPY владеет результатом и может собрать поля при различающихся wire/native-layout. С lifetime наложение требует точных смещений, размера, порядка байтов, выравнивания и допустимых значений до создания ссылки. Динамические/optional/compact/QPS поля не подходят whole-record overlay. Именованные регионы создают настоящие вложенные типы. Явные _unchecked API сохраняются.
