# compact · QSL 0.2.0

Записывает ранги чисел и кодов ограниченной длины с выбранной схемой разрядностью. Для u8(0..7), u8(0..31), u16(0..1023) это 3/5/10 бит. Обычные opt_table и BM поддерживаются; predict_seq и несовместимые scalar-QPS/native-overlay режимы отклоняются. alignment добавляет padding. Checked-десериализации по-прежнему нужен safety.
