# `compact` — спецификация атрибута

**Статус:** реализовано, кроме оговорки для `safety`: только флаг в этой версии.

## Синтаксис

```qsl
&Dense[compact] { u8(0..7) flags; u8(0..31) rank; u16(0..1023) code; }
```

## Точная механика и wire-эффект

Ранги (3,5,10 бит) упакованы в 18 бит. Для фиксированного compact-layout генератор использует постоянные маски и сдвиги. Генерируются comp_size/comp_write/comp_read; fast path может быть развёрнут.

## Ограничения и недопустимые сочетания

Не универсальный компрессор: `String` и числовые типы не сжимаются единым алгоритмом. `opt_table`/`predict_seq` запрещены; `alignment` может добавить padding.

## Контракт исполнения

При изменении схемы обе стороны должны использовать совместимую ревизию формата. Путь `unsafe` не подтверждает корректность произвольного сетевого ввода; источник, объём данных и диапазоны должны соответствовать схеме.

## Что измерять

Сравнивай полную запись и чтение на одних данных, отдельно метаданные и payload; фиксируй размер сообщения, аллокации, CPU, измерительный профиль и p99. Исходный пример замера:
`records/Dense/read/current` — [all-estimates.csv](../../data/all-estimates.csv).

## Исходная реализация

`qsl/src/types.rs FLAG_COMPACT; interpreter.rs emit_compact_flat_write/read`.
