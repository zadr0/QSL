# loyal_cache · QSL 0.2.0

loyal_cache или cache=N включает выход в CachedFrame вызывающей стороны с константной проверкой ёмкости. Нужна конечная граница схемы; недостаточная явно заданная ёмкость отклоняется. Значения и MAX_DATA_SIZE проверяются. Это подготовка выходной памяти, не кэш ранее прочитанных значений и не универсальная мемоизация.
