# quant · QSL 0.2.0

quant=Q2/Q4/Q8/Q16 — явный синоним qps=Qn. qps без значения означает Q16, quant без значения отклоняется. Одновременное указание двух имён отклоняется. Квант входит в идентичность использующего его формата.
