# `optionals=bitmap` — спецификация атрибута

**Статус:** реализовано, кроме оговорки для `safety`: только флаг в этой версии.

## Синтаксис

```qsl
&User[compact,optionals=bitmap] { u32(10..17) id; string? name; }
```

## Точная механика и wire-эффект

Для каждого объявленного поля используется бит, в том числе для required. Первое поле — бит 31, второе — бит 30 первого little-endian u32; присутствие обязательного поля всегда 1.

## Ограничения и недопустимые сочетания

Добавляет целые 4-байтные слова метаданных, даже если optional один. Менять порядок схемы нельзя без обновления протокола. Несовместим с sequential-атрибутами.

## Контракт исполнения

При изменении схемы обе стороны должны использовать совместимую ревизию формата. Путь `unsafe` не подтверждает корректность произвольного сетевого ввода; источник, объём данных и диапазоны должны соответствовать схеме.

## Что измерять

Сравнивай полную запись и чтение на одних данных, отдельно метаданные и payload; фиксируй размер сообщения, аллокации, CPU, измерительный профиль и p99. Исходный пример замера:
`records/User/read/current` — [all-estimates.csv](../../data/all-estimates.csv).

## Исходная реализация

`qsl/src/types.rs bitmap_words; interpreter.rs emit_fast_header`.
