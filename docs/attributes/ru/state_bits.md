# state_bits · QSL 0.2.0

state_bits=Q1/Q2/Q4/Q8/Q16 выбирает самостоятельный старый D/presence-index формат, не QPS-сжатие. Его ограничения полей и анализа самостоятельны. С BM не сочетается. Хранение таблицы и wire-представление присутствия различаются; переход старых кадров описан в полном руководстве.
