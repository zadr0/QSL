# state_bits

Явный режим совместимости со старым представлением D/u32 и статическими индексами. `[state_bits]` использует Q1; поддержаны Q1/Q2/Q4/Q8/Q16. Это отдельный механизм, отличный от числового сжатия QPS v2. Формат другой стороны автоматически не определяется; схемы и конфигурации должны быть согласованы. [Архитектура](../../architecture.ru.md).
