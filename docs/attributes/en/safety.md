# safety · QSL 0.2.0

Generate checked deserialization and checked-into. Standalone validate and checked serialization remain explicit controls. Validate bounds, domain, UTF-8, compressed output, optional metadata and aggregate useful budget before publishing a result. It does not remove unchecked APIs and cannot prove arbitrary user codec implementations sound. MAX_DATA_SIZE defaults to 65535.
