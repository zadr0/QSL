# aggressive · QSL 0.2.0

Opt into bounded inline ownership and supported optional niche/rank representations. STACK_LIMIT defaults to 256 data bytes per inline string/array buffer. It is not a whole-process or total stack-frame bound. Larger ordinary COPY buffers retain their codec in String/Vec. The option changes native storage/initialization, not permission to read invalid input.
