# quant · QSL 0.2.0

quant=Q2/Q4/Q8/Q16 is an explicit alias for qps=Qn. Bare qps means Q16; bare quant is rejected. Specifying both names together is rejected. Quantum participates in the wire identity when the selected format uses it.
