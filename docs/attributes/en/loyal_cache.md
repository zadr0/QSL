# loyal_cache · QSL 0.2.0

loyal_cache or cache=N enables a caller-owned CachedFrame output path with compile-time capacity validation. A finite schema bound is required; an insufficient explicit cache capacity is rejected. Values and MAX_DATA_SIZE remain checked. It prepares output storage, not a cache of previously decoded values or universal memoization.
