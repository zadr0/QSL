QSL / RUST / MAIN

Exchange of data described in advance

QSL analyzes a schema at build time and generates concrete Rust structures and codecs. Types, bounds, field order and storage are explicit. Generated code reads and writes bytes at runtime.

One schema, separate responsibilities

01 / ARCHITECTURE

Shared contracts and runtime execution belong to qsl-core. The lexer collects and validates schemas; the interpreter generates Rust. The qsl facade preserves ::qsl paths in generated code.

qsl-coreTypes, errors, I/O, strings, buffersqsl-lexerQSL / DEQ → validated schemasqsl-interpreterSchemas → generated Rust sourceqslApplication facade and compatible paths

Schema

&Message[safety,opt_table] {
    u32 id;
    str(1..255) text;
    u16? code;
}

Required fields always precede optional fields. Attributes are independent choices.

Build-time generation

use qsl_interpreter::prelude::*;
let builder = build_qsl_schem("schemas")?;
let rust = builder.use_interpreter()?;

The builder retains the schema collection. Another backend can implement SchemaBackend; LLVM is not implemented.

UTF-8: type, storage and read mode

02 / STORAGE

Variable strings use String, &str, StackString and InlineString only. New/reuse describes destination handling. Guard and byte slices are not QSL string representations.

Storage plan · x86-64

Rust typeString
Object24 B
Useful bytes255 B

This models declared capacity, not measured RSS. String capacity may exceed its length; allocator overhead is excluded. rustc determines the final ABI.

STACK_LIMIT defaults to 256 B. Larger ordinary inline strings fall back to String. Fixed native byte fields retain [u8; N]; borrowed text requires the original frame to remain alive.

BM, predict_seq and opt_table

03 / OPTIONAL
BM

Presence

A mask of optional fields only. Analysis selects 8–128 bits; traversal visits the set bits.

PS

Length index

predict_seq derives admissible sequences from payload length. It is inactive with BM.

OT

Reader dispatch

opt_table maps a validated marker to a reader. It preserves the format and can combine with BM or PS.

&Packet[safety,optionals=bitmap,opt_table] {
    u8 id;   // 9
    u16? a;  // 0x1234
    u8? b;   // 7
}

Marker a = 1 occupies the most significant bit. trailing_zeros reads b → a; the writer uses the same order.

Mask11000000
Markers2 → 1
ReadersOT[1] → OT[0]
C009073412

The blue byte is metadata. This models a concrete format verified in Rust; it does not simulate execution time.

QPS is separate lossless operand/range packing for numbers. It does not predict optional-field presence. UTF-8 compression with decompress=true uses its own codec.

Current string measurements

04 / CRITERION

Nine decoding cases compare new/reuse and &str. The main set contains 1024 Cyrillic scalars = 2048 useful bytes. The String control uses 255 ASCII scalars = 255 bytes.

P = M / T · M is original useful bytes; T is nanoseconds per string.

Measured under background load; not accepted as strict speed evidence. Estimated average background during the run: 8.2%.
