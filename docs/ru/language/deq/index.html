Builder и DEQ

Builder — способ описать схему средствами Rust. DEQ — файл констант и общих настроек. Оба пути приходят к одному анализу и формату; при одинаковых входных условиях результат должен быть одинаковым.

Как собирается схема

Заголовок раздела «Как собирается схема»

QslBuilder хранит настройки и набор схем. В schem вызываются name, field и методы типов; build проверяет все объявления. use_interpreter выбирает генерацию Rust. Полный build.rs.

Методы и аргументы

Заголовок раздела «Методы и аргументы»

name(name: &str)

Создаёт новую схему. Имя используется для Rust-типа; следующая операция field относится к этой схеме.

name: &str
Непустое допустимое имя Rust.

field(name: &str)

Задаёт имя следующего поля. Само поле добавляется следующим методом типа, например u32 или str.

name: &str
Имя поля; одинаковые имена запрещены.

u32(min: u32, max: u32, default: u32, optional: bool)

Объявляет число. Для остальных целых типов набор аргументов такой же, но их Rust-тип соответствует выбранной ширине.

min, max
Включительные границы допустимых значений. В compact влияют на число записываемых битов.
default
Начальное значение нового объекта; обязано принадлежать диапазону. Не записывается вместо отсутствующего optional.
optional: bool
true разрешает отсутствие. Все optional-поля должны идти после обязательных.

str(min: u32, max: u32, decompress: bool, optional: bool)

Объявляет строку UTF-8. Длина считается в байтах: «Яa» занимает 3 B.

min, max
Включительные границы числа UTF-8 байтов. max участвует в выборе заголовка и вместимости хранения.
decompress: bool
true выбирает строковый кодек QSL-LZ. Кодек использует raw, если сжатие невыгодно.
optional: bool
Разрешает отсутствие всей строки; пустая строка и отсутствие — разные состояния.

array::<T>(min: u32, max: u32, optional: bool)

Объявляет массив переменной длины. T — тип элемента с метаданными QslFieldType.

T
Тип каждого элемента. Бюджет памяти учитывает размер T, а wire использует кодек элемента.
min, max
Число элементов, а не байтов. Влияет на длину, capacity и выбор Vec/InlineArray.
optional: bool
Разрешает отсутствие массива; пустой массив остаётся отдельным значением.

fstr(size: u32, optional: bool) / farray::<T>(size: u32, optional: bool)

Фиксирует длину. Заголовок переменной длины не нужен; выбор хранения всё равно подчиняется STACK_LIMIT.

size: u32
Для fstr — байты, для farray — элементы.

padding(bits: u32)

Добавляет нулевые биты в wire. Кратные байту значения сохраняют прежнее поведение Padding; небайтовые значения требуют compact.

bits: u32
Число битов. Checked reader проверяет, что они нулевые.

domain(domain, default_bits: Option<u128>, optional: bool)

Задаёт точный интервал, прогрессию или множество значений. Ранг обратимо сопоставляется исходному значению.

domain
NumericDomain: задаёт ширину, знак и допустимые значения.
default_bits
None — без явного initializer; Some хранит native bit pattern начального значения.

compact() / auto() / inline() / ot() / ps() / bm() / q16()

Эти методы не принимают аргументов и включают конкретную механику. Их совместимость проверяется при build.

compact / q16
Меняют кодирование wire; одинаковая схема должна быть у обеих сторон.
auto / inline
auto меняет физический layout; inline задаёт политику Rust-методов.
ps / ot / bm
Индекс длины / читатель по тегу / маска присутствия соответственно.

group(enabled: bool) / pointing(enabled: bool) / aggresive(shift: bool, bitmap: bool)

Разрешает только доказанные оптимизации. Флаг сам по себе не делает произвольный объект пригодным для memcpy или SIMD.

enabled: bool
true разрешает анализ кандидата; unsafe-условия и профиль остаются обязательными.
shift / bitmap
Физическая длина len+1 / приватные optional-слоты и маска. Это не wire BM.

dyn_line(width: u32, revision: u32) / dyn_index(width: u32, strict: bool, revision: u32)

Выбирает отдельный формат dyn v1. Поля получают явные метатеги через tag(u64).

width: u32
line: 16/32/64; index: 32/64. index16 не поддержан.
strict: bool
Выбирает строгий вариант индексной схемы.
revision: u32
Версия схемы в согласованном dyn-контракте.

Настройки DEQ

Заголовок раздела «Настройки DEQ»

MAX_DATA_SIZE

Заголовок раздела «MAX_DATA_SIZE»

По умолчанию: 65535 B. max_data_size(bytes: u32).

Ограничивает входной кадр, восстановление и суммарные данные до выделения памяти. Не является лимитом RSS.

STACK_LIMIT

Заголовок раздела «STACK_LIMIT»

По умолчанию: 256 B. stack_limit(bytes: u32).

Отдельный строгий предел встроенного хранения строк и массивов. Большой max_data_size не увеличивает его.

QSL_RT

Заголовок раздела «QSL_RT»

По умолчанию: false. with_rt().

Включает статические слоты только для подходящих ограниченных схем.

QSL_RT_DEFAULT

Заголовок раздела «QSL_RT_DEFAULT»

По умолчанию: 16. default_rt_slots(slots: u32).

Число одновременно занятых слотов на схему: от 1 до 64. При исчерпании — ошибка.

USE_HASH

Заголовок раздела «USE_HASH»

По умолчанию: xxHash. use_xxhash128().

xxHash выбирает XXH3-64, xxHash128 — XXH3-128. Хэш не заменяет аутентификацию.

CPU_PROFILE

Заголовок раздела «CPU_PROFILE»

По умолчанию: portable. cpu_profile(CpuProfile).

portable либо kaby_lake. Меняет выбор допустимых инструкций, а не wire-формат.

Константы

Заголовок раздела «Константы»

Типизированные целочисленные константы вычисляются при сборке; поддержаны точные u128/i128. Дубликаты, переполнения и неверные значения вызывают диагностику.
