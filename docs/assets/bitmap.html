BM определяет порядок, OT выбирает функцию. predict_seq при BM не применяется. Это разбор байтов, а не замер скорости JavaScript.

BM determines traversal; OT selects a function. predict_seq is inactive under BM. This is a byte model, not a JavaScript speed estimate.
