# Dyn v1: все режимы QSL 0.4.0

Intel Core i5-7400, Windows 11, Rust 1.98.0, target-cpu=native, thin LTO, codegen-units=1. Два противоположных порядка, 1 с прогрева + 3 с измерения, 200 выборок на случай, CI 99%. Среднее двух независимых медиан; исходные CI не объединяются. Фоновая нагрузка записана, система не считается полностью простаивающей.

Отдельный release-бинарник и два отдельных прохода: **60 случаев × 2**, 32 профиля, включая owned/borrowed. Измерены все семь разрешённых сочетаний режима и ширины: line 16/32/64; index(dynamic) 32/64; index(strict) 32/64. Для четырёх индексных режимов добавлена числовая схема compact. index16 и compact+line не поддерживаются анализатором QSL 0.4.0; они не выдаются за измеренные случаи.

Те же numeric, optionals и text_1024, что в межпротокольном сравнении. Теги явные, revision=1, MAX_DATA_SIZE=8192. Все чтения checked: заголовок, границы, значения, UTF-8 и обязательные поля проверяются кодеком; полный consumer включён. Подготовка источников исключена.

Временная память передаётся явно: line использует u64 на запись, индекс — u32. Локальные массивы scratch имеют ёмкость четыре записи для чисел/optionals и две для текста; их инициализация входит в измеренное чтение. Размеры массивов: 32/16 байт для четырёх записей line/index, 16/8 байт для двух. Heap-выделение scratch не выполняется. borrowed-текст имеет отдельный контракт и не ранжируется с owned.

## Результат на четырёх u32

- `line16` использует 44 B и читает запись за 101.68 нс. У `line64` кадр занимает 92 B, а чтение — 89.73 нс.
- Оба 32-битных индекса занимают 48 B. Чтение в strict заняло 221.49 нс, в dynamic — 283.54 нс.
- `compact` уменьшил кадр dynamic32 до 38 B. Чтение заняло 382.70 нс.

У чисел и опциональных чисел чтение обходится без heap-аллокаций. Чтение строки 1024 B с владением выделяет память один раз. При заимствовании строки аллокаций нет. Счётчики по всем операциям есть в CSV.

## Проверка и ограничения

Все 256 записей проверены для каждого профиля. Тесты отклоняют усечённые кадры, неверную ревизию, ненулевые reserved, другой режим/ширину и недостаточный scratch. Тесты проверки не входят во время замера. Line хранит tag+Span возле каждого значения; индексные режимы имеют таблицу и конечное смещение. strict не обязан уменьшать кадр: полная ширина индексной записи такая же. Сравнение с обычным QSL взято из другого прохода в тот же день; для точных малых различий учитывайте фоновую нагрузку.

Строк с дрейфом >10%: 1. Фон вне процесса: 0.55 ядра / 0.59 ядра.
