# QSL 0.4.0 — трансмутация, StackString и QSL-LZ

## Трансмутация

Фиксированная структура 16 B с выравниванием 8 B. Генератор подтверждает совпадение Rust-представления и кадра на little-endian машине. Все пути проверяют диапазон вложенного поля и читают одинаковые значения. Копирование возвращает самостоятельный объект, overlay заимствует вход. Для overlay проверено отклонение смещённого на 1 байт адреса. [Схемы](qsl-features/schemas/features.qsl)

|Путь чтения|Время, нс|Дрейф, %|
|---|---|---|
|Трансмутация с копией|3.67|0.22|
|Копия со смещённого адреса|3.86|0.02|
|Чтение по полям|4.80|1.29|
|Заимствование overlay|4.18|1.76|

## Строки

256 записей по 1024 байта на корпус. Запись использует готовый объект и буфер. Чтение создаёт владеющий объект и вычисляет XXH3 по всему UTF-8. Размер объекта включает встроенное хранилище, но у String дополнительные 1024 байта выделяются отдельно. StackString сохраняет тот же wire. QSL-LZ работает через InlineString. При неудачном коротком поиске совпадения используется raw с двухбайтным заголовком. Повторяющиеся строки журнала с длинным периодом и переменным префиксом демонстрируют это поведение, а период 16 байт проверяет сжатую ветку.
