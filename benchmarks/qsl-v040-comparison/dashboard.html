Бенчмарки QSL 0.4.0

Время и память кодека

Одна запись в памяти → бинарный кадр или бинарный кадр → владеющая Rust-структура. Замер Criterion проходит без транспорта.

Модель API использует Reading, Update и Notice. Отдельные наборы Heartbeat и Event используют ту же общую оболочку. У всех протоколов одинаковые значения и признаки присутствия, включая Some(0), Some(false) и пустые строки.

Контракт и память

Запись принимает готовую модель по значению и создаёт выходной буфер. Клонирование для повторов идёт вне таймера. Чтение создаёт одну общую Rust-модель с владением данными. В QSL дочерние переменные кадры вкладываются как байтовые массивы с длиной, а ветка выбирается по дискриминанту. Цена обработки дочерних кадров учтена. Protobuf использует oneof, Cap’n Proto — union, Bincode — enum.

Счётчик памяти измеряет вызовы alloc/realloc и сумму запрошенных байтов на операцию. Размер общей Rust-модели в таблице относится только к её встроенной части. Числа — средние двух медиан на прогретом наборе из 256 записей.

HTTP API · запрос и нормализованный ответ

HTTP/1.1 keep-alive, localhost, 8 VU. Сервер декодирует POST, проверяет вариант сообщения, увеличивает revision и кодирует ответ. k6 сверяет его побайтно.

RPS — завершённые запросы за 8 с измерения. В квадратных скобках RPS двух отдельных прогонов. p95 приведён как среднее двух независимых p95. Размеры тел — среднее по набору из 256 записей. Быстрые ответы могут попадать ниже разрешения таймера k6.

CSV HTTP по прогонам · Методика HTTP

TCP · Heartbeat и 32 Events

Постоянное соединение. Heartbeat: один запрос и один бинарный ответ. Events: пакет из 32 кадров и подтверждение с количеством и контрольной суммой.

В объём входят 4 байта длины каждого кадра и ACK размера 16 байт на пакет. Следующее измерение начинается после проверки ответа. Events/с рассчитаны только по активному времени пакетов, включая ожидание ACK. TCP/IP и системные накладные расходы передачи здесь учтены во времени.

Функции QSL

Трансмутация

Тот же 16-байтный кадр при каждом чтении. Обычное чтение и копирование возвращают объект. Overlay заимствует входной буфер и требует выравнивания. В измерение входят проверки и общий потребитель полей.

String, StackString и QSL-LZ

У каждой записи текст длиной 1024 байта. Запись использует готовый буфер, чтение проверяет и потребляет все байты. Период 16 байт включает сжатую ветку. Шум и журнал с длинным периодом показывают raw-ветку QSL-LZ.

Экономия при вашей нагрузке

Подставляются измеренные средние размеры. Можно обнулить любой поток. Частоты в примере заданы как параметры модели нагрузки.

Расчёт на сутки суммирует объём в обе стороны. Для API берутся тела HTTP, для сокета — длины кадра, Heartbeat/pong и доля ACK на событие. Сюда не входят HTTP-заголовки, TCP/IP, TLS, ретрансляции и правила тарификации провайдера.
