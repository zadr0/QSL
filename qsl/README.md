# QSL

[Русский](#русский) · [English](#english)

## Русский

QSL — язык описания данных и генератор специализированного Rust-кода для бинарного обмена. Стороны заранее согласуют поля, порядок, диапазоны и кодеки. При сборке QSL анализирует схему и создаёт конкретные структуры и методы; приложение обменивается их байтами.

QSL рассчитан на внутренние протоколы, IPC, телеметрию и повторяющиеся записи с известным форматом. Разработчик задаёт границы памяти, владение и проверку входа. Согласование версий, маршрутизация и TLS организуются приложением.

## English

QSL is a data-description language and a generator of specialized Rust binary codecs. Peers agree on field order, value ranges, lengths and codecs. QSL analyzes schemas during the Cargo build and emits concrete Rust structures and methods.

It targets controlled internal protocols, IPC, telemetry and repeated records with known layouts. Developers specify memory bounds, ownership and input validation. Applications provide version negotiation, routing and TLS.

## Краткий курс / Quick course

Create an application with cargo new qsl-demo and add four files. Keep the package section generated by Cargo.

Создайте приложение через cargo new qsl-demo и добавьте четыре файла. Сохраните секцию package, созданную Cargo.

### 1. Cargo.toml

Use the same version for generation and runtime. Для генерации и исполнения используется одинаковая версия.

```toml
[dependencies]
qsl = "=0.1.0"

[build-dependencies]
qsl = "=0.1.0"
```

### 2. user.qsl

```qsl
&User[safety] {
    u64 id;
    str(1..100) name;
}
```

### 3. build.rs

```rust,ignore
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let out = std::path::PathBuf::from(std::env::var_os("OUT_DIR").unwrap());
    qsl::build_qsl_files(&["user.qsl"], &[], out)?;
    Ok(())
}
```

### 4. src/main.rs

```rust,ignore
include!(concat!(env!("OUT_DIR"), "/qsl_gen.rs"));

fn main() -> qsl::QslResult<()> {
    let user = User {
        id: 42,
        name: "Ada".into(),
    };
    let bytes = user.serialize_checked()?;
    let restored = User::deserialize_checked(&bytes)?;
    assert_eq!((restored.id, restored.name.as_str()), (42, "Ada"));
    println!("{}: {} ({} bytes)", restored.id, restored.name, bytes.len());
    Ok(())
}
```

```text
cargo run
42: Ada (15 bytes)
```

### Правила / Rules

- Обязательные поля идут перед опциональными. Required fields precede optional fields.
- Границы строк задаются в байтах UTF-8, массивов — в элементах. String bounds count UTF-8 bytes; array bounds count elements.
- safety добавляет checked-чтение. Unsafe-методы требуют корректного кадра и памяти. safety adds checked reads; unsafe methods require valid frames and storage.
- Checked-чтение проверяет фактические длины, диапазоны, UTF-8 и общий MAX_DATA_SIZE. Каждый LZ-токен ограничивается до записи. Checked reads validate actual lengths, domains, UTF-8 and MAX_DATA_SIZE; every LZ run is bounded before output writes.
- Схема и влияющие на wire опции определяют формат; стороны обновляются согласованно. The schema and wire-affecting options define the format; peers coordinate upgrades.

### Следующие шаги / Next steps

| Option | Назначение / Purpose |
|---|---|
| aggressive | Встроенное хранение ограниченных значений / bounded inline ownership |
| qps=Q16 | Обратимая упаковка числовых полей / lossless scalar numeric packing |
| predict_seq | Индекс состояния по длине / length-derived state index |
| opt_table | Тег optional-поля → читатель / optional tag → reader |
| lifetime | Заимствование поддерживаемых полей / borrowed supported fields |

Атрибуты опциональны. По умолчанию MAX_DATA_SIZE = 65535 B и STACK_LIMIT = 256 B данных на встроенный буфер. Более крупные COPY-строки и массивы используют String/Vec. Строки и длины не квантуются QPS; QSL-LZ — отдельный строковый кодек.

Attributes are opt-in. Defaults are MAX_DATA_SIZE = 65535 B and STACK_LIMIT = 256 data bytes per inline buffer. Larger COPY strings and arrays use String/Vec. QPS does not quantize strings or lengths; QSL-LZ is a separate string codec.

Features: rust-macros imports marked Rust definitions during analysis; native enables Windows native memory and socket support; diagnostics exposes diagnostic cursor APIs. Rust 1.98 is the declared baseline for this first release. During the 0.1 series, coordinate API and wire changes explicitly.
