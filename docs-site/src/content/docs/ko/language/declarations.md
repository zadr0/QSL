스키마 파일에는 선언이 하나 이상 들어 있습니다. 선언 하나가 Rust 타입 하나가 됩니다.

```qsl
&Name[attribute, attribute=value] {
    type field;
    type field|modifier=value|;
    type? optional_field;
}
```
구성 요소 | 의미
---|---
`&Name` | `Name`이라는 타입을 선언합니다.
`[ ... ]` | 타입 전체에 적용되는 속성. 생략할 수 있습니다. [속성 레퍼런스](/reference/attributes/) 참고.
`type field;` | 필수 필드.
`type? field;` | 옵셔널 필드. 범위가 있으면 `?`는 범위 앞에 씁니다: `u16?(0..1023) level;`.
`\|...\|` | 필드 하나에 적용되는 수정자. 이름과 세미콜론 사이에 씁니다.
## Rust에서의 옵셔널 필드 {#optional-fields-in-rust}

옵셔널 문자열 필드와 옵셔널 배열 필드는 구조체의 공개 `Option<T>` 필드가 됩니다.

옵셔널 숫자 필드는 비공개 필드에 저장됩니다. 값은 같은 이름의 메서드로 읽고 `set_<name>`으로 바꿉니다. `set_<name>`은 필드 범위를 벗어난 값에 `InvalidValue`를 반환합니다. 이런 필드가 있는 타입에는 `try_new` 생성자가 생깁니다. 이 생성자는 모든 필드를 선언 순서대로 받아 값을 검사합니다.

```qsl
&Reading[safety] { u32 id; u8? level; }
```

```rust
let mut r = Reading::try_new(42, Some(7))?;
assert_eq!(r.level(), Some(7));
r.set_level(None)?;
```

## 필드 순서

필수 필드는 옵셔널 필드보다 앞에 와야 합니다. QSL은 속성 유무와 관계없이 모든 타입에 이 규칙을 적용합니다.

```qsl
&Ok    { u32 id; u16? code; }
&Error { u16? code; u32 id; }   // 빌드 에러: 옵셔널 필드 뒤에 필수 필드
```

필수 값은 선언 순서대로 와이어에 쓰입니다. 옵셔널 값의 순서는 [옵셔널 필드 모드](/language/optionals/)에 따라 달라집니다.

## 태그

컴파일러는 각 필드에 선언 순서대로 1부터 태그를 붙입니다. 태그를 직접 지정할 수는 없습니다. 옵셔널 필드의 기본 인코딩은 태그를 저장하므로([옵셔널 필드](/language/optionals/) 참고) 필드 순서를 바꾸면 포맷이 바뀝니다.

`optionals=bitmap`이 없는 타입은 필드를 최대 64개까지 가질 수 있습니다.

## 범위

`A..B`는 양 끝을 포함하는 범위입니다. 의미는 타입에 따라 다릅니다.

```qsl
&Limits {
    u8(1..3)          kind;    // 값 범위: 1, 2, 3
    str(1..100)       name;    // UTF-8 1~100바이트
    str(4)            tag;     // 정확히 4바이트, [u8; 4]가 됨
    array<u16>(0..16) samples; // 요소 0~16개
}
```

검증 메서드는 값 범위를 강제합니다. `compact`를 쓰면 범위가 필드의 비트 수도 정합니다. 문자열 범위는 문자 수가 아니라 UTF-8 바이트 수를 셉니다. `"Ада"`는 6바이트입니다.

## 상수 표현식

경계에는 정수와 이름 있는 상수로 된 표현식을 쓸 수 있습니다.

```qsl
&Frame {
    str(1..MAX_NAME) name;
    array<u8>(0..MAX_NAME * 2) payload;
}
```

표현식은 `+ - * / %`, 단항 마이너스, 괄호, 정수 타입 `u8`부터 `i64`까지에 대한 `sizeof(T)`, 이름 있는 상수를 지원합니다. 상수는 [DEQ 파일](/language/deq/)의 `!define`이나 타입 본문 안의 `#NAME = expression;` 줄에서 정의합니다. 타입 본문 안에서 정의한 상수는 그 뒤에 오는 줄에서 쓸 수 있습니다. 오버플로와 0으로 나누기는 빌드 에러입니다.

## 주석

`//`는 줄 주석을 시작합니다. `/* ... */`는 블록 주석입니다.

```qsl
&Packet[safety] {
    u8 id;      // 메시지 종류
    u16? a;     /* 대부분의 프레임에는 없음 */
}
```

## 거부되는 스키마

다음 경우 빌드가 실패합니다.

- 옵셔널 필드 뒤에 오는 필수 필드
- 중복된 필드 이름이나 타입 이름, Rust 키워드이거나 `__qsl_`로 시작하는 필드 이름
- 잘못되었거나 뒤집힌 경계, 정수 타입의 범위를 벗어난 범위
- 알 수 없거나 반복된 속성과 수정자
- `optionals=bitmap` 없이 필드가 64개를 넘는 경우, 또는 `optionals=bitmap`이 있을 때 옵셔널 필드가 128개를 넘는 경우

내장 타입이 아닌 타입 이름은 [커스텀 타입](/guides/custom-types/)으로 처리되며 Rust 구현이 필요합니다. 커스텀 타입에는 범위를 붙일 수 없습니다. 내장 타입 목록은 [타입](/language/types/)에 있습니다.
