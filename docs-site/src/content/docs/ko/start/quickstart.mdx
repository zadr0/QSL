Rust 1.98 이상이 필요합니다. 결과물은 `User` 값을 바이트로 인코딩한 뒤 다시 디코딩하는 프로그램입니다.

<FileTree>
- qsl-demo/
  - Cargo.toml
  - build.rs
  - user.qsl
  - src/
    - main.rs
</FileTree>

<Steps>

1. 프로젝트를 만듭니다.

   ```sh
   cargo new qsl-demo
   cd qsl-demo
   ```

2. `Cargo.toml`에 `qsl`을 두 번 추가합니다. 프로그램용으로 `[dependencies]` 아래에, `build.rs`용으로 `[build-dependencies]` 아래에 넣습니다. Cargo가 만든 `[package]` 섹션은 그대로 둡니다. 두 곳의 버전은 같아야 합니다.

   ```toml title="Cargo.toml" ins={7,9-10}
   [package]
   name = "qsl-demo"
   version = "0.1.0"
   edition = "2024"

   [dependencies]
   qsl = "=0.4.0"

   [build-dependencies]
   qsl = "=0.4.0"
   ```

3. `Cargo.toml`과 같은 위치의 `user.qsl`에 메시지를 기술합니다.

   ```qsl title="user.qsl"
   &User[safety] {
       u64 id;
       str(1..100) name;
   }
   ```

   `&User`는 타입을 선언합니다. `u64 id`는 이름이 `id`이고 타입이 `u64`인 필드입니다. `str(1..100)`은 UTF-8로 1~100바이트인 문자열입니다. `[safety]`는 아래에서 쓰는 검증 디코드 메서드를 추가합니다.

4. 빌드 타임에 Rust 코드를 생성합니다. 프로젝트 루트에 `build.rs`를 만듭니다.

   ```rust title="build.rs"
   fn main() -> Result<(), Box<dyn std::error::Error>> {
       let out = std::path::PathBuf::from(std::env::var_os("OUT_DIR").unwrap());
       qsl::build_qsl_files(&["user.qsl"], &[], out)?;
       Ok(())
   }
   ```

   `build_qsl_files`는 `OUT_DIR`에 `qsl_gen.rs`를 쓰고, `user.qsl`이 바뀌면 `build.rs`를 다시 실행하라고 Cargo에 알립니다. 두 번째 인자는 `.deq` 설정 파일 목록입니다. 지금은 비어 있습니다.

5. `src/main.rs`에 생성된 파일을 포함합니다. 이 파일이 `User`와 그 메서드를 정의하므로 `use` 줄은 필요 없습니다.

   ```rust title="src/main.rs"
   include!(concat!(env!("OUT_DIR"), "/qsl_gen.rs"));

   fn main() -> qsl::QslResult<()> {
       let user = User {
           id: 42,
           name: "Ada".into(),
       };
       let bytes = user.serialize_checked()?;
       let restored = User::deserialize_checked(&bytes)?;
       assert_eq!((restored.id, restored.name.as_str()), (42, "Ada"));
       println!("{}: {} ({} bytes)", restored.id, restored.name, bytes.len());
       Ok(())
   }
   ```

6. 실행합니다.

   ```sh
   cargo run
   ```

   ```text
   42: Ada (15 bytes)
   ```

</Steps>

## 어떻게 동작했나

프레임은 15바이트입니다. `id`에 8바이트, `name`의 길이 접두사에 4바이트, UTF-8에 3바이트입니다. 스키마는 `name`에 1~100바이트를 허용하므로, `deserialize_checked`는 길이 접두사가 이 범위를 벗어난 프레임을 문자열을 할당하기 전에 거부합니다.

`serialize_checked`는 값을 쓰기 전에 스키마에 맞는지 검사합니다. 두 메서드 모두 `qsl::QslResult`를 반환합니다. 에러 타입은 [`QslError`](/reference/errors/)입니다.

## 미리 알아 둘 규칙

- 필수 필드가 먼저 옵니다. 옵셔널 필드 뒤에 필수 필드가 있으면 빌드 에러입니다.
- 문자열과 배열의 경계는 양 끝을 포함합니다. 문자열은 UTF-8 바이트 수로, 배열은 요소 수로 셉니다.
- `deserialize_checked`와 `deserialize_checked_into`는 `[safety]`가 있는 타입에만 생성됩니다. 비검증 디코더는 항상 생성되며, 유효한 프레임을 전제로 합니다.
- `MAX_DATA_SIZE`는 프레임과 디코딩된 데이터의 크기를 제한합니다. 기본값은 65535바이트입니다. [DEQ 파일](/language/deq/)에서 바꿉니다.
