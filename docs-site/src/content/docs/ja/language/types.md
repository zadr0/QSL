## 組み込み型
スキーマ | Rust の型 | 備考
---|---|---
`u8` `u16` `u32` `u64` `i8` `i16` `i32` `i64` | 同じプリミティブ型 |
`T(A..B)`（`T` は整数型） | 同じプリミティブ型 | 値は範囲内である必要があります。`compact` と `qps` でワイヤ上のサイズを縮められます。
`flags(N)` | `N` に応じて `u8`、`u16`、`u32`、`u64` のいずれか | `N` は 1〜64。`N` より上位のビットはゼロである必要があります。
`str`、`string`、`String` | `String` | 可変長。長さの制限は `MAX_DATA_SIZE` だけです。
`str(A..B)` | `String` または別の文字列型 | 両端を含む上下限を UTF-8 のバイト数で指定します。[文字列](/language/strings/)を参照してください。
`str(N)` | `[u8; N]` | ちょうど `N` バイトの UTF-8。ワイヤ上に長さはありません。`N` が `STACK_LIMIT` を超える場合は `String`。
`array<T>`、`vec<T>` | `Vec<T>` | `T` は組み込みの整数型か[登録済みのプリミティブ](/guides/custom-types/#validated-scalar-wrappers)。
`array<T>(N)` | `[T; N]` | ちょうど `N` 要素。ワイヤ上に要素数はありません。配列が `STACK_LIMIT` バイトより大きい場合は `Vec<T>`。
`array<T>(A..B)` | `Vec<T>` | 両端を含む要素数。`aggressive` を指定し、`STACK_LIMIT` に収まる場合は `InlineArray<T, B>`。
`padding(N)` | `()` | ワイヤ上に `N` バイトのゼロ。
`T?` | `Option<T>` | オプションフィールド。数値のオプションフィールドはアクセサメソッドを使います。[宣言](/language/declarations/#optional-fields-in-rust)を参照してください。
その他の名前 | 利用者の Rust 型 | `QslCustom` を実装する必要があります。[カスタム型](/guides/custom-types/)を参照してください。
`lifetime` 属性を指定すると、文字列と `u8` 配列は `&'a str` と `&'a [u8]` として入力から借用されます。

## デフォルトのワイヤエンコーディング

フォーマットを変える属性がない場合、エンコーディングは次のとおりです。

- **整数**は、ネイティブ幅のリトルエンディアンです。`u16(0..1023)` は 2 バイトです。
- **文字列**は、`u32` のバイト長に UTF-8 のバイト列が続きます。固定長の `str(N)` には長さがありません。
- **動的配列**は、`u32` の要素数に要素が続きます。固定長配列には要素数がありません。
- **必須フィールド**は宣言順に並びます。
- **オプションフィールド**は、値の前に存在情報のメタデータを追加します。[オプションフィールド](/language/optionals/)を参照してください。

フレームは型情報を持ちません。両側がスキーマを知っている必要があります。

## ワイヤサイズとオブジェクトサイズ

この 2 つは互いに独立しています。

```qsl
&Reading[compact] {
    u8(0..7)     kind;
    u8(0..31)    channel;
    u16(0..1023) value;
}
```

ワイヤ上では 3 + 5 + 10 = 18 ビットで、3 バイトとして書き込まれます。メモリ上の `Reading` は `u8`、`u8`、`u16` を持つ `#[repr(C)]` 構造体で、4 バイトです。このサイズは `Reading::NATIVE_BYTES` に入っています。
