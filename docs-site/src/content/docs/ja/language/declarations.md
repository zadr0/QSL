スキーマファイルには 1 つ以上の宣言を書きます。1 つの宣言が 1 つの Rust 型になります。

```qsl
&Name[attribute, attribute=value] {
    type field;
    type field|modifier=value|;
    type? optional_field;
}
```
要素 | 意味
---|---
`&Name` | `Name` という型を宣言します。
`[ ... ]` | 型全体に対する属性。省略できます。[属性リファレンス](/reference/attributes/)を参照してください。
`type field;` | 必須フィールド。
`type? field;` | オプションフィールド。範囲を付ける場合、`?` は範囲の前に置きます（`u16?(0..1023) level;`）。
`\|...\|` | 1 つのフィールドに対する修飾子。フィールド名とセミコロンの間に書きます。
## Rust でのオプションフィールド {#optional-fields-in-rust}

オプションの文字列フィールドと配列フィールドは、構造体の公開フィールド `Option<T>` になります。

オプションの数値フィールドは非公開のフィールドに格納されます。値は同じ名前のメソッドで読み取り、`set_<name>` で変更します。`set_<name>` は、フィールドの範囲外の値に対して `InvalidValue` を返します。このようなフィールドを持つ型には `try_new` コンストラクタが生成されます。`try_new` はすべてのフィールドを宣言順に受け取り、値をチェックします。

```qsl
&Reading[safety] { u32 id; u8? level; }
```

```rust
let mut r = Reading::try_new(42, Some(7))?;
assert_eq!(r.level(), Some(7));
r.set_level(None)?;
```

## フィールドの順序

必須フィールドは、オプションフィールドより前に置く必要があります。QSL は、属性の有無にかかわらずすべての型にこのルールを適用します。

```qsl
&Ok    { u32 id; u16? code; }
&Error { u16? code; u32 id; }   // ビルドエラー：オプションの後に必須フィールド
```

必須の値は、宣言順にワイヤへ書き込まれます。オプションの値の順序は、[オプションフィールドのモード](/language/optionals/)によって決まります。

## タグ

コンパイラは各フィールドに、宣言順に 1 から始まるタグを割り当てます。タグを自分で指定することはできません。オプションフィールドのデフォルトのエンコーディングはタグを格納するため（[オプションフィールド](/language/optionals/)を参照）、フィールドを並べ替えるとフォーマットが変わります。

`optionals=bitmap` を指定しない型のフィールドは、最大 64 個です。

## 範囲

`A..B` は両端を含む範囲です。意味は型によって異なります。

```qsl
&Limits {
    u8(1..3)          kind;    // 値の範囲：1、2、3 のいずれか
    str(1..100)       name;    // UTF-8 で 1〜100 バイト
    str(4)            tag;     // ちょうど 4 バイト。[u8; 4] になる
    array<u16>(0..16) samples; // 0〜16 要素
}
```

チェック付きメソッドは値の範囲を強制します。`compact` を指定すると、値の範囲はフィールドが占めるビット数も決めます。文字列の範囲は文字数ではなく UTF-8 のバイト数で数えます。`"Ада"` は 6 バイトです。

## 定数式

上下限には、整数と名前付き定数を使った式を書けます。

```qsl
&Frame {
    str(1..MAX_NAME) name;
    array<u8>(0..MAX_NAME * 2) payload;
}
```

式では `+ - * / %`、単項マイナス、括弧、整数型 `u8`〜`i64` に対する `sizeof(T)`、名前付き定数を使えます。定数は、[DEQ ファイル](/language/deq/)の `!define` か、型本体の中の `#NAME = expression;` という行で定義します。後者で定義した定数は、それ以降の行で使えます。オーバーフローとゼロ除算はビルドエラーです。

## コメント

`//` は行コメントを開始します。`/* ... */` はブロックコメントです。

```qsl
&Packet[safety] {
    u8 id;      // メッセージの種類
    u16? a;     /* ほとんどのフレームでは存在しない */
}
```

## 拒否されるもの

次の場合、ビルドは失敗します。

- オプションフィールドの後に必須フィールドがある。
- フィールド名や型名が重複している。フィールド名が Rust のキーワードであるか、`__qsl_` で始まる。
- 上下限が無効または逆転している。範囲が整数型の範囲を超えている。
- 属性や修飾子が未知のものであるか、重複している。
- `optionals=bitmap` なしでフィールドが 64 個を超える。または `optionals=bitmap` ありでオプションフィールドが 128 個を超える。

組み込みでない型名は[カスタム型](/guides/custom-types/)として扱われ、Rust 側の実装が必要です。カスタム型には範囲を付けられません。組み込み型の一覧は[型](/language/types/)を参照してください。
