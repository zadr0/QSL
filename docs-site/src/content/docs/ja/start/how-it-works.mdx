スキーマに依存する処理は、すべてクレートのビルド中に行われます。実行時に動くのは生成されたコードだけです。

## ビルド時

`build.rs` は、`.qsl` スキーマと `.deq` 設定ファイルを渡して `qsl::build_qsl_files` を呼び出します。この呼び出しが最初の 5 つの手順を実行します。6 つ目の手順は、Cargo がクレートをコンパイルするときに行われます。

1. **パース。** レキサとパーサがスキーマと DEQ ファイルを読み、`MAX_LEN * 2` のような定数式を評価し、各フィールドに宣言順でタグを割り当てます。
2. **展開とチェック。** Rust テンプレートとネイティブリージョンを展開します。名前、フィールド順、属性の組み合わせをチェックします。
3. **解析。** `qsl-core` のコードが、ビット幅、長さの上下限、オプションフィールドのレイアウト、スキーマハッシュを計算します。
4. **ストレージの選択。** 文字列フィールドと配列フィールドそれぞれの Rust 型を、属性と `STACK_LIMIT` に基づいて決めます。
5. **生成。** インタプリタが構造体、メソッド、静的テーブルを `OUT_DIR` 内の `qsl_gen.rs` に書き出します。
6. **コンパイル。** `rustc` が生成ファイルを利用者のコードと一緒にコンパイルします。

範囲の逆転やフィールド名の重複といったスキーマのエラーがあると、`build.rs` はエラーを返し、ビルドはそのメッセージとともに失敗します。

## 生成コードの使い方

`qsl_gen.rs` に含まれるのはアイテム（構造体、`impl` ブロック、static）です。モジュールレベルでインクルードしてください。[クイックスタート](/start/quickstart/)のようにクレートルートに置くか、専用のモジュールに置きます。

```rust title="src/main.rs"
mod wire {
    include!(concat!(env!("OUT_DIR"), "/qsl_gen.rs"));
}

use wire::Packet;

fn roundtrip(packet: &Packet) -> qsl::QslResult<Packet> {
    let bytes = packet.serialize_checked()?;  // 値をチェックしてから書き込む
    Packet::deserialize_checked(&bytes)       // 読みながらチェックする
}
```

生成コードはランタイムを `::qsl::...` として参照します。そのため、クレートは `[build-dependencies]` だけでなく `[dependencies]` にも `qsl` を追加する必要があります。

## 実行時

生成されたメソッドには、各フィールドの型と幅が定数として埋め込まれています。フレームは型記述子を持たず、実行時にスキーマを参照する処理もありません。

チェック付きデコーダは、1 つのカーソルで読み取りと検証を同時に行います。事前に別の検証パスを実行することはありません。

## 一致しない 2 つのサイズ

**ワイヤサイズ**はエンコードされたフレームの長さです。**オブジェクトサイズ**は生成された構造体の `size_of::<T>()` です。生成される構造体は `#[repr(C)]` なので、フィールドは宣言順に並び、Rust がアラインメントのためにパディングを追加します。`u16(0..1023)` のフィールドは、`compact` ではワイヤ上で 10 ビットですが、メモリ上では 2 バイトの `u16` のままです。各型は、メモリ上のサイズとアラインメントを表す定数 `NATIVE_BYTES` と `NATIVE_ALIGNMENT` を持ちます。

## コードの所在
フェーズ | クレート | 主なファイル
---|---|---
パース、展開 | `qsl-lexer` | `lexer.rs`、`parser.rs`、`deq.rs`、`builder.rs`
解析 | `qsl-core` | `analysis.rs`、`schema_hash.rs`、`types.rs`
生成 | `qsl-interpreter` | `frontend.rs`、`interpreter.rs`、`codegen_*.rs`
実行時 | `qsl-core`（`qsl` から再エクスポート） | `io.rs`、`bit_io.rs`、`validation.rs`、`strings.rs`
詳しくは[アーキテクチャ](/internals/architecture/)と[ワイヤフォーマット](/internals/wire-format/)を参照してください。
