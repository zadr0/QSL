<LandingSection title="Du schreibst das Schema, QSL schreibt den Code" id="usage" split>

Quick Schema Language (QSL) ist eine Schemasprache für Rust. Du beschreibst eine Nachricht einmal: ihre Felder, den Wertebereich jeder Zahl, wie lang ein String sein darf. Bei `cargo build` macht QSL daraus ein Struct und den Code, der es in Bytes schreibt und wieder einliest.

Du schreibst keinen Codec von Hand, und das Schema wird zur Laufzeit nicht geparst. Mit `[safety]`, wie hier, kommen Bytes, die nicht zum Schema passen, als Fehler zurück, nicht als `User`. Die beiden anderen Dateien des Programms findest du im [Schnellstart](/start/quickstart/).

<div slot="aside">

```qsl title="user.qsl"
&User[safety] {
    u64 id;
    str(1..100) name;
}
```
