<LandingSection title="Vous écrivez le schéma, QSL écrit le code" id="usage" split>

Quick Schema Language (QSL) est un langage de schéma pour Rust. Vous décrivez un message une seule fois : ses champs, la plage de chaque nombre, la longueur que peut avoir une chaîne. Pendant `cargo build`, QSL en fait une structure, avec le code qui l’écrit en octets et la relit.

Aucun codec à écrire à la main, et le schéma n’est pas analysé à l’exécution. Avec `[safety]`, comme ici, des octets qui ne respectent pas le schéma produisent une erreur, pas un `User`. Les deux autres fichiers du programme se trouvent dans le [démarrage rapide](/start/quickstart/).

<div slot="aside">

```qsl title="user.qsl"
&User[safety] {
    u64 id;
    str(1..100) name;
}
```
