title: "От схемы к байтам"
description: "Документация QSL: От схемы к байтам."
---

QSL обрабатывает схему во время сборки Cargo. Приложение обменивается байтами через сгенерированные Rust-методы.

1. Лексер выделяет имена, литералы и атрибуты.
2. Парсер собирает описания полей и конфигурации.
3. Анализ проверяет диапазоны, порядок обязательных и опциональных полей и совместимость опций.
4. Rust-backend выбирает хранение, вычисляет смещения и записывает исходный код в OUT_DIR.
5. Rust-компилятор собирает этот код вместе с runtime qsl-core.
6. Сериализация записывает кадр; checked-декодирование проверяет байты и восстанавливает значение.

Порядок в памяти, порядок передачи и семантика схемы независимы. auto меняет физическую раскладку; auto-wire требует явной версии для изменения канонического wire-порядка. predict_seq анализирует длину payload, opt_table выбирает читатель по тегу, QPS выполняет обратимое сжатие.


```qsl
&Record[safety,compact] { u32(0..4095) id; }
```

```rust
let record = Record { id: 42 };
let wire = record.serialize_checked()?;
assert_eq!(Record::deserialize_checked(&wire)?.id, 42);
```
