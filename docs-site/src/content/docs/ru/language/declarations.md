---

Схема начинается с имени и содержит поля в порядке сообщения. Для обычного формата обязательные поля не записывают тег; опциональные находятся в конце. Теги назначает компилятор.

```qsl
&User[safety] {
    u64 id;
    str(1..100) name;
    u8? age;
}
```

Знак `?` разрешает отсутствие поля. Пустая строка и отсутствующая строка различаются. Начальное значение объекта не заменяет отсутствующее поле.

Атрибуты схемы записываются в квадратных скобках после имени. Модификатор поля относится только к этому полю. Все дополнительные механики опциональны; порядок required → optional обязателен.
