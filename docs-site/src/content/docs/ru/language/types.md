Выберите тип значения, затем задайте ограничения. Тип Rust в сгенерированном объекте может зависеть от storage-политики: например строка станет String, &str или ограниченным контейнером.
Семейство | Значение
---|---
`u8…u128 / i8…i128` | Целые числа 8–128 бит; диапазон и дискретные домены.
`f32 / f64` | Числа с плавающей точкой по выбранному кодеку.
`bool / char / flags` | Логическое значение, Unicode scalar и битовые флаги.
`str / string` | UTF-8 с фиксированной или ограниченной длиной.
`array<T>` | Массив с кодеком элемента T и собственной длиной.
`Custom` | Пользовательский тип с явно зарегистрированным контрактом.
