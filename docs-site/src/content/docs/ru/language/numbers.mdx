---
title: "Числовые домены"
description: "Документация QSL: Числовые домены."
---


Для непрерывного интервала:


$$
N=max-min+1,\qquad w=\lceil\log_2N\rceil,\qquad rank=x-min.
$$


Реальная ширина вычисляется точно как bit_length(max−min), без float. У константы 0 бит. Полный диапазон u128 учитывается отдельно, без переполнения cardinality. Signed-домены используют проверенные native bit patterns и wrapping-арифметику там, где это необходимо для восстановления.

Raw пишет исходные little-endian числа. COMPACT пишет rank в обычный LSB-first поток. Один и тот же Rust-тип не означает побитовую совместимость raw и COMPACT. alignment добавляет byte barrier после поля, сохраняя порядок.

Опциональные явные ограничения:

```qsl
&Discrete[safety,compact] {
    i32(-9..9) temperature|step=3|;
    i128 state|values=[-1,0,1]|;
}
```

Для step: $r=(x-\min)/s$. Шаг положителен, верхняя граница достигается из нижней. Off-step значения отклоняются. Для values множество непустое, без повторов; числовой порядок задаёт rank. При сочетании каждый элемент соответствует диапазону и шагу. В raw эти ограничения валидируют исходное число.

Rank обратим на объявленном домене. Spare-коды проверяются checked-reader до восстановления. Это не разрешение округлять данные. step/values — выбранный локальный синтаксис явных доменов, а не обязательный механизм QSL. Положительные широкие QSL-литералы не сужаются через i128; ограничения общего DEQ-реестра рассмотрены выше.
