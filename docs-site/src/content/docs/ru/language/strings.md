Строка QSL — текст UTF-8. Длина задаётся в байтах: «Яa» занимает 3 B. Ограничение относится к восстановленному тексту, поэтому поддельный заголовок сжатого кадра не разрешает запись за пределы буфера.

## Как выбирается память

**String** владеет динамическим буфером. **&str** заимствует проверенный raw-текст из входа, который должен оставаться живым. **StackString** и **InlineString** хранят ограниченное количество байтов внутри объекта. Фиксированная строка использует **[u8; N]** в поддержанном fixed-режиме.

Выбор зависит от lifetime, aggressive, кодека и STACK_LIMIT. Лимит строг и для явных inline-режимов. new создаёт значение в назначении, reuse повторно использует подходящий буфер; это способы чтения, а не новые типы строк.

## Когда строка сжимается {#compressed-strings}

QSL-LZ ищет ограниченные повторения и выбирает сжатый вариант только при реальном выигрыше. Иначе записываются raw-байты. Частые символы сами по себе не гарантируют выигрыш: имеют значение длина повторения, расстояние и служебные данные.


Массивы описаны [отдельно](/language/arrays/); [QPS](/guides/smaller-frames/) — другой обратимый кодек.

InlineString сохраняет кодек при размещении на стеке или в Box на heap. Большие heap-строки восстанавливаются прямо в назначение. StackString и InlineArray содержат ограниченную ёмкость внутри объекта. Явное aggressive[shift=true] может выбрать NonZero-длину для строк и массивов, сохраняя различие None и Some(empty).

no_std исключает std, но не alloc. qsl-core всегда использует #![no_std]. Возможность alloc включена по умолчанию и предоставляет alloc String/Vec, SerOut и восстановление в heap. Аллокатор задаёт приложение; QSL не объявляет глобальный аллокатор. Для работы только с переданной памятью отключаются default features.

[Limits](/reference/limits/) · [Memory](/guides/manual-layout/)

Генератор выбирает тип выхода по доказанному максимуму кадра. Если он не превышает STACK_LIMIT, включая равенство, обычная сериализация возвращает `StackOut<N>`; больший или неизвестный максимум выбирает alloc::`Vec<u8>`. Передаваемые заголовки входят в порог; служебная длина и выравнивание самого выходного объекта — нет.
