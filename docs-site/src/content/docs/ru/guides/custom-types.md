QSL предоставляет три разных расширения. **Шаблон** добавляет поля в схему. **Числовая обёртка** связывает целое число с Rust-типом и диапазоном. **Пользовательский кодек** задаёт собственное бинарное представление фиксированного размера. Выбирать следует минимальный подходящий контракт.

## Шаблоны из Rust

Атрибут `#[qsl::qsl_macro]` или его синоним `#[qsl::schem_macro]` ставится на обычную Rust-структуру с именованными полями. Исходная структура сохраняется. Атрибут реализует `QslMacro`: при сборке он возвращает описания полей, а не сериализованные значения.

Если поле шаблона называется `meta` и содержит `id`, в схеме появляется `meta_id`. Вложенные шаблоны раскрываются рекурсивно: путь `meta.location.zone` становится `meta_location_zone`. Теги назначаются заново после раскрытия. Поэтому опциональные поля шаблона должны оказаться после всех обязательных полей итоговой схемы. Циклы, одинаковые имена и неподдержанные опциональные группы шаблонов отклоняются.

~~~rust
#[qsl::qsl_macro]
struct Location { zone: u16 }

#[qsl::qsl_macro]
struct Meta { id: u64, location: Location }

let mut builder = qsl::QslBuilder::new();
builder.schem(|schema| {
    schema.name("Packet").safety();
    schema.field("meta").r#macro::<Meta>();
});
let schemas = builder.build()?;
~~~

Сгенерированный Packet содержит `meta_id: u64` и `meta_location_zone: u16`. Вложенного поля Meta в нём нет. Раскрытие шаблона отличается от native-региона: регион намеренно создаёт отдельную вложенную Rust-структуру.

Для импорта исходных Rust-файлов нужны feature `rust-macros` в build-зависимости и `from_files_with_rust` либо `build_qsl_files_with_rust`. Импортёр читает поддержанные объявления, но не исполняет произвольные выражения Rust. Типизированный Builder использует `QslFieldType` для встроенных полей и `QslMacro` для вложенных шаблонов. Для generic и условных объявлений есть ограничения: неизвестный тип нельзя молча считать массивом байтов.

## Обёртки целых чисел

`qsl_primitive!` объявляет или регистрирует tuple-структуру из одного поля. Форма объявления добавляет `repr(transparent)`, Copy и Clone. Форма регистрации проверяет существующий тип. Поддерживаются целочисленные представления до 64 бит из закрытого набора; наличие встроенных u128/i128 в QSL не расширяет контракт этого макроса.

~~~rust
qsl::qsl_primitive!(pub struct DeviceId(u32); range=(1,100););

let builder = qsl::QslSchemaBuilder::new()
    .with_primitive::<DeviceId>("DeviceId")?
    .with_source("&Packet[safety]{DeviceId id;}")?;
~~~

Во время компиляции проверяются размер, выравнивание, нулевое смещение tuple-поля, отсутствие Drop и корректность диапазона. Макрос реализует метаданные `QslPrimitive`, а также чтение, запись и проверки `QslCustom`. Регистрировать определение нужно до разбора схемы, в которой указан этот тип. Совпадение имён само по себе не доказывает представление внешнего типа.

В raw-режиме DeviceId хранится как little-endian u32. Его compact-кодек записывает ранг с округлением до целого числа байтов. Здесь 100 значений требуют 7 бит ранга и занимают 1 байт пользовательского кодека. Это не означает, что любой custom-тип упаковывается побитово вместе с соседними полями.

$$
N=b-a+1,\qquad r=x-a.
$$

$$
w=\lceil\log_2 N\rceil,\qquad B_{\mathrm{custom}}=\lceil w/8\rceil.
$$

Для константного диапазона ширина ранга равна нулю. Лишние ранги и raw-значения вне диапазона отклоняются checked-методами. Публичному tuple-полю по-прежнему можно присвоить неверное значение; допустимость конкретного значения обеспечивает проверка либо ограниченный конструктор приложения. Макрос не создаёт нишу Option автоматически.

## Проверки native-примитивов

`qsl_native_primitive!(DeviceId, u32)` дополнительно реализует `NativeField` в приложении. Он применяется после регистрации примитива, если явный native-регион содержит такую обёртку. Проверяются метаданные представления и числовой диапазон до публикации результата безопасного копирования или просмотра. Макрос не инициализирует padding, не отменяет выравнивание и не разрешает читать произвольный Rust-объект как передаваемые байты.

`#[qsl_macro(aggressive_transmutate)]` — отдельная форма для native-структуры: фиксированные именованные поля без generic-параметров, repr(C), допустимое явное выравнивание, Copy/Clone и проверки конечных полей. В этой форме фиксированное поле InlineString преобразуется в массив байтов UTF-8. Варианты packed/Rust/transparent отклоняются. Перед использованием раскладки нужно проверить получившийся тип.

## Собственный бинарный формат

`QslCustom` нужен, если числовой примитив или шаблон не описывает требуемый формат. Следует задать `SIZE` и `COMP_SIZE`, реализовать небезопасные чтение и запись для raw/compact. Метод `qsl_validate` отклоняет неверные входные байты, а `qsl_validate_values` — значения, которые кодек не может корректно записать. По умолчанию неизвестный кодек отклоняется checked-операциями.

Валидатор должен подтверждать именно то представление, которое затем читает unsafe-декодер. Одного имени Rust-типа или его размера недостаточно. Разработчик отвечает за инициализацию байтов, допустимость значений, ёмкость, отсутствие пересечения областей и инварианты своего формата. Runtime-контракты ядра не используют аллокатор; метаданные схем и регистрация макросов относятся к сборке и находятся в lexer.
