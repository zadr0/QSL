### QSL-LZ

```qsl
&Text[safety] {
    str(1..100) name|decompress=true|;
}
```

Это отдельный строковый кодек. Encoder выбирает raw-представление, когда сжатие невыгодно; размеры сравниваются с учётом заголовка выбранного формата. Текущий raw-copy порог коротких строк — 32 B.

InlineString использует общий length/mode header: 1 B при max≤127, 2 B при max≤32767, далее 4 B в допустимом диапазоне. FixedCompressedString имеет отдельный контракт; его метаданные нельзя выводить из этого правила без анализа типа.

Checked decompressor проверяет каждый literal/match run, backward distance, фактический вывод и вместимость. Одного отпечатка длины недостаточно. Поддельная длина не разрешает выход за буфер; восстановленный объём ограничивается независимо от размера сжатого входа.

### QPS

QPS — обратимое operand-кодирование. При разложении на частное/остаток сохраняются необходимые для точного восстановления части. Квант по умолчанию Q16; явные варианты Q2/Q4/Q8/Q16. Состояние optional по длине QPS не предсказывает.
Путь | Контракт
---|---
Scalar payload specialization | Известные числовые домены и выбранные kernel; доступность задаёт PayloadQuantPlan
ByteQps / QPB3 | Общие точные byte groups, отдельная оболочка 16 B, исходная длина, scratch/restoration
DomainInteger использует допустимый общий путь вместо отдельной scalar-специализации. Для safety-схем без dyn генератор создаёт отдельный QPB3 API всего payload, включая UTF-8, массивы и широкие числа: serialize_qps_to и deserialize_qps_into (для Lifetime — восстановление с заимствованием). Обычный serialize сохраняет scalar-prefix wire и QSL-LZ; вызов whole-frame API выбирается явно. Длины восстанавливаются точно вместе с исходным кадром.

QPB3 имеет метаданные и режим несжимаемых данных. Гарантировать уменьшение любых произвольных байтов без потерь невозможно. Буфер восстановления может быть больше wire; резервировать его нужно по проверенному исходному максимуму.

Подготовленный scalar API serialize_quantized_to возвращает QuantizedFrame. Некоторым kernel нужны **QUANT_PADDING_BYTES инициализированных доступных байтов после wire-длины**. Это private storage, не часть сообщения: as_slice его не передаёт. Такой контракт отличается от точного обычного checked-reader. Размер quantum не обязывает каждый load читать 128 бит.
