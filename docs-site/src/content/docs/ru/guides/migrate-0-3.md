Сайт описывает локальный dev-qsl, а не обещает наличие всех API в crates.io. В новые локальные возможности входят общий Builder, dyn v1, числовые домены, regional IR, auto-wire v1 и CPU-профили. Обе стороны обмена должны использовать совместимую схему и ревизию wire.
