**Quick Schema Language (QSL)** — язык схем и генератор кода для **бинарной сериализации в Rust**. Вы один раз описываете сообщение: его поля, диапазон каждого числа, допустимую длину строки. Во время `cargo build` QSL превращает это описание в структуру и код, который записывает её в байты и читает обратно.

Кодек не нужно писать вручную, а схему программа во время работы не разбирает. С `[safety]`, как здесь, байты, не соответствующие схеме, возвращаются ошибкой, а не значением `User`. Остальные два файла программы — в [быстром старте](/start/quickstart/).

<div slot="aside">

```qsl title="user.qsl"
&User[safety] {
    u64 id;
    str(1..100) name;
}
```
