---
title: "Empaquetado BMI2"
description: "QSL — Empaquetado BMI2"
---

Cuatro campos u32 de 0..4095 ocupan 12 bits cada uno y forman una trama de 6 bytes. El perfil Kaby Lake permite el writer PEXT admitido si BMI2 está habilitado para el destino. El reader generado sigue siendo escalar. El kernel PDEP separado restaura valores exactos; se comprueba el CPU antes de llamar a la ISA.

```qsl
&Bmi2Packet[compact,aggressive[group=true],safety] {
    u32(0..4095) f0;
    u32(0..4095) f1;
    u32(0..4095) f2;
    u32(0..4095) f3;
}
```

```text title="settings.deq"
!config CPU_PROFILE = kaby_lake;
```

```rust
use qsl::optimizer::kernels;
let values = [0u32, 1, 2047, 4095];
kernels::validate4(values, [12; 4])?;
let scalar = kernels::pack4::<12, 12, 12, 12>(values);
#[cfg(target_arch = "x86_64")]
if std::is_x86_feature_detected!("bmi2") {
    // CPU support and all value ranges have been checked.
    let packed = unsafe { kernels::x86::pack4_bmi2::<12, 12, 12, 12>(&values) };
    assert_eq!(packed, scalar);
    let restored = unsafe { kernels::x86::unpack4_bmi2::<12, 12, 12, 12>(packed) };
    assert_eq!(restored, values);
}
```
