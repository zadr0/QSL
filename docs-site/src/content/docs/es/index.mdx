<LandingSection title="Tú escribes el esquema, QSL escribe el código" id="usage" split>

Quick Schema Language (QSL) es un lenguaje de esquemas para Rust. Describes un mensaje una sola vez: sus campos, el rango de cada número, lo larga que puede ser una cadena. Durante `cargo build`, QSL convierte esa descripción en un struct y en el código que lo escribe en bytes y lo vuelve a leer.

No hay ningún códec que escribir a mano, y el esquema no se analiza en tiempo de ejecución. Con `[safety]`, como aquí, los bytes que no encajan con el esquema te llegan como un error, no como un `User`. Los otros dos archivos del programa están en el [inicio rápido](/start/quickstart/).

<div slot="aside">

```qsl title="user.qsl"
&User[safety] {
    u64 id;
    str(1..100) name;
}
```
