Edición local de desarrollo · 2026-11-14.

MAX_DATA_SIZE vale 65535 B por defecto y limita entrada, restauración y datos acumulados. STACK_LIMIT vale 256 B para cadenas y arrays internos. No representan un límite de RSS. dyn index16 no está soportado; LLVM y el handshake QBProto son planes futuros. Las combinaciones inválidas se rechazan al generar.
