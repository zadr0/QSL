Edição local de desenvolvimento · 2026-11-14.

MAX_DATA_SIZE tem padrão de 65535 B e limita entrada, restauração e dados acumulados. STACK_LIMIT tem padrão de 256 B para strings e arrays internos. Não são limites de RSS. dyn index16 não é suportado; LLVM e handshake QBProto são planos futuros. Combinações inválidas são rejeitadas na geração.
