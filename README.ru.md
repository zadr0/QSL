# QSL — Quick Schema Language

QSL описывает заранее согласованные данные и генерирует специализированные бинарные кодеки Rust при сборке. Схема определяет порядок полей, диапазоны, длины, владение и проверки. В работающем приложении вызываются скомпилированные методы.

Инструмент предназначен для управляемых внутренних протоколов, телеметрии и повторяющихся записей с известными границами. Согласование схем, транспорт, TLS и внешнюю IPC-память предоставляет приложение.

## Подключение

```toml
[dependencies]
qsl = "=0.4.0"

[build-dependencies]
qsl = "=0.4.0"
```

```qsl
&User[safety] {
    u64 id;
    str(1..100) name;
}
```

Во время сборки `qsl::build_qsl_files` записывает Rust в `OUT_DIR`. Приложение подключает его через `include!` и использует `serialize_checked` и `deserialize_checked`. [Полный запускаемый пример](examples/quickstart) содержит Cargo.toml, build.rs и main.rs.

## Память и безопасность

qsl-core работает в no_std; feature alloc предоставляет String, Vec и Box. Аллокатор задаёт приложение. При доказанном максимуме кадра не больше STACK_LIMIT, включая равенство, обычный выход — StackOut<N>; больший или неизвестный максимум выбирает Vec. serialize_checked_to использует буфер приложения. Подготовленный unsafe reuse сохраняет пригодные ёмкости без роста.

Обязательные поля идут перед опциональными. Строковые длины считаются в байтах UTF-8, массивы — в элементах. Checked-reader проверяет границы, значения, UTF-8 и бюджет MAX_DATA_SIZE; распаковка проверяет каждый токен. Отдельные unsafe-методы сохраняют контракт вызывающего кода.

## Возможности

- compact упаковывает значения по заданным числовым доменам.
- predict_seq использует длину payload; opt_table выбирает читатель по тегу; bitmap хранит присутствие опциональных полей.
- QPS выполняет обратимое кодирование с Q2/Q4/Q8/Q16; по умолчанию Q16. Строковый QSL-LZ имеет независимый кодек и raw fallback.
- Rust-шаблоны раскрываются в поля схем; пользовательские примитивы задают представление и проверки.
- auto оптимизирует физическую раскладку, сохраняя wire-порядок; auto-wire требует отдельного явного разрешения.
- qsl-rt предоставляет однопоточные и межпоточные пулы; заполненный пул возвращает PoolExhausted.
- Строгий и облегчённый хэши вычисляются при анализе и не заменяют согласование формата или аутентификацию.
