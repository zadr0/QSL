# QSL — специализированный бинарный обмен

[English](README.en.md) · [Полное руководство](docs/guide.ru.md) · [Интерактивная документация](docs/index.html) · [API](docs/API.ru.md)

QSL генерирует Rust-код для обмена заранее описанными данными. Типы, диапазоны, порядок полей и владение памятью задают формат до запуска. Дополнительные механизмы включаются явно; порядок [обязательные][опциональные] обязателен.

**QPS — точное сжатие операндами. Предиктование по длине выполняет opt_table.**

```qsl
&Message[safety,opt_table] {
    u32 id;
    str(0..4096) text|binary_opt=guard|;
    u16? code;
}
```

В руководстве описаны все подсистемы: язык QSL/DEQ, обычное и compact-кодирование, optional/bitmap/predict_seq/opt_table, String и UTF-8-обёртки, строковый LZ, оба QPS-пути, валидация, inline, Rust-макросы, custom-типы, SerOut, RT, native-память, IPC и сокеты. Ограничения и контракты перечислены вместе с вариантами API.

## Общий QPS

ByteQps<Q2/Q4/Q8/Q16> принимает любые сериализованные байты, включая UTF-8 и массивы, и восстанавливает их без потерь. Заголовок QPB3 хранит исходную длину без квантования; он занимает 16 B. Packed выбирается только при выигрыше полного кадра, иначе используется явный raw-режим. Для чисел сохранена отдельная статическая специализация.

Общий путь явно вызывается через ByteQps или serialize_qps_to / deserialize_qps_into. Обычный Serializable не меняет формат неявно. Числовой QUANT_ACTIVE описывает специализацию, а не отсутствие общего кодека. Объединение четырёх u8 даёт операнд u32, но не гарантирует сжатия всех 32 бит.

## Измерения и ограничения

[Полный отчёт](docs/features.ru.md) и [интерактивные графики](docs/index.html#measurements): полезный P=M/T, время, wire-размеры, CI 99% и кардиограммы реальных выборок Criterion. M — исходные полезные байты. Новое владеющее значение, reuse и borrow подписаны отдельно.

Основной проход охватывает 95 случаев; отдельный UTF-8/целый кадр — 8 случаев. После локальной оптимизации повторены только 22 случая общего QPS: всего 103 разных случая и 125 наблюдений. Предыдущие снимки N=1/2/3/5/10 сохранены отдельно. Уменьшение кадра не гарантирует ускорения, а общий QPS не получает автоматического допуска в горячий путь.
