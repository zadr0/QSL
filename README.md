# QSL

[Русский](README.ru.md) · [English](README.en.md) · [Interactive guide / Интерактивное руководство](docs/index.html)

QSL specializes binary exchange using declared schemas, domains, ownership and buffers.

QSL специализирует бинарный обмен по явно заданным схемам, диапазонам, владению и буферам.

QPS = exact operand compression. opt_table = length prediction.
