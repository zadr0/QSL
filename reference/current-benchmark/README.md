# Current measured harness / Текущий стенд

This repository publishes documentation, not a Cargo workspace. Use the matching dev-qsl checkout containing qsl/ and qsl-macros/. Copy this directory to qsl-bench/current/ and reference/tools to qsl-bench/tools if needed. Source hashes are in reference/current-source-manifest.json.

Этот репозиторий публикует документацию, а не Cargo workspace. Нужна соответствующая рабочая копия dev-qsl с qsl/ и qsl-macros/. При необходимости скопируйте каталог в qsl-bench/current/, а reference/tools — в qsl-bench/tools. Хеши исходников указаны в reference/current-source-manifest.json.

Commands and buffer contracts: docs/performance.en.md / docs/performance.ru.md. The harness measures QSL only.
